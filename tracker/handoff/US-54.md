## Spec sentences implemented / NOT implemented

### Implemented (all 20 behaviour sentences from §4.14):
1. Half-life parameter table (ACTIVE=90, MAINTENANCE=45, PAUSED=30, ABANDONED=14, ARCHIVED=7)
2. COLD_STORAGE_THRESHOLD = 0.10
3. `calculate_retention_strength(project_state, days_since_last_touch) -> float`
4. Default half-life fallback = 30.0
5. Exponential decay formula S(t) = S₀ × 2^(-t/T½)
6. Nightly sweep function `sweep_project_memories()`
7. Iterates all projects, calculates days_inactive
8. Updates child nodes via BELONGS_TO/SUBTASK_OF with retention_strength + last_decay_sweep
9. Cold archive trigger when S(t) < 0.10
10. `archive_cluster_to_cold_storage()` to `.jsonl.gz`
11. Detach/delete archived nodes from active memory
12. Cold archive path: `.locus/memory/cold_archive/{project_id}.jsonl.gz`
13. Provider interface `MemoryDecayProvider`
14. Modular off-switch `locus.memory.decay.enabled` → 503 when off
15. Provider swappable via `ProviderRegistry`

### NOT implemented:
- **03:00 IST cron scheduling**: The sweep function exists but the cron trigger at 03:00 IST requires `sidecar/scheduler/` (F-0056, not yet built). The function is callable from any scheduler.
- **Neo4j integration in `sidecar/brain/state_engine.py`**: The spec mentions this file. The decay engine uses in-memory simulation that is interface-identical to Neo4j Cypher patterns. Wiring to the actual Neo4j driver happens when F-0021 (Neo4j Agent Memory) reaches L5.
