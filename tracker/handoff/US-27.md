## Security (anything found, even if outside this story)
- Tool arguments stored in telemetry tracking are hashed with SHA-256 to prevent sensitive variable or password capture.
- User profile documents are written strictly to local user home (`~/.locus/PROFILE.md`), never leaked over unauthenticated networks.
- All learning endpoints bind strictly to loopback (`127.0.0.1`), never `0.0.0.0`.
- All endpoints enforce the 503 off-switch when disabled.
