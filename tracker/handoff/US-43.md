## Plan (written before coding)
- Implement `BaseToolOutputAccumulatorProvider`, `TruncationType`, `OutputAccumulatorConfig`, `OutputSnapshot`, and `FullOutputResult` in `sidecar/providers/tool_output_accumulator.py`.
- Re-export Tool Output Accumulator provider contracts in `sidecar/providers/__init__.py`.
- Implement `ToolOutputAccumulatorProvider` in `sidecar/tool_output_accumulator.py`:
  - `create_accumulator`: Initialises a thread-safe streaming session with configurable `max_lines`, `max_bytes`, and `temp_file_prefix`.
  - `append`: Incremental UTF-8 chunk ingestion, updating decoded line counts and byte metrics, rolling tail buffer maintenance, and transparent disk spillover once thresholds are reached.
  - `snapshot`: Instant bounded tail retrieval indicating whether truncation occurred and whether it was triggered by line count or byte limits.
  - `finish`: Closes active streaming intake, flushes buffers, and locks accumulator against subsequent appends.
  - `read_full_output`: Retrieves unabridged output from disk/memory or applies clean middle omission formatting (`[... X bytes omitted ...]`) preserving head and tail within target budgets.
  - `close`: Releases file descriptors and purges session state.
- Implement TypeScript client in `locus-extension/src/tool-output-accumulator.ts` and re-export in `locus-extension/src/index.ts`.
- Register routes in `sidecar/service.py`: `/tools/accumulator/create`, `/tools/accumulator/{id}/append`, `/tools/accumulator/{id}/snapshot`, `/tools/accumulator/{id}/finish`, `/tools/accumulator/{id}/full`, `DELETE /tools/accumulator/{id}`, and `/tools/accumulator/config` with 503 off-switch.
- Unit tests in `tests/unit/test_tool_output_accumulator.py` and integration tests in `tests/integration/test_tool_output_accumulator_service.py`.
- Pi table:
  - Need: Bounded streaming tool output tracking, display tail snapshots, disk spillover for full logs, and omission-cut retrieval.
  - Pi mechanism: `packages/coding-agent/src/core/tools/output-accumulator.ts:35-258` implements TypeScript `OutputAccumulator` for local terminal tools.
  - What Locus adds: Locus extends this mechanism into a full sidecar service provider (`ToolOutputAccumulatorProvider`) accessible via REST endpoints and TypeScript client wrapper, enabling remote, subagent, and background job output streaming with unified bounded buffers.
  - Why Pi's is not enough: Pi's implementation is tightly bound to in-process Node.js child processes and cannot be accessed or inspected across sidecar services, subagents, or remote web hooks.
