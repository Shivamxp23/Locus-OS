# US-40 handoff - Gemini 3.8 Flash, 2026-10-20

## Plan (written before coding)
- Implement `BaseGitToolsProvider`, `GitStatusResult`, `GitDiffResult`, `GitCommitResult`, and `GitLogEntry` in `sidecar/providers/git_tools.py`.
- Re-export Git Tools provider contracts in `sidecar/providers/__init__.py`.
- Implement `GitToolsProvider` in `sidecar/git_tools.py`:
  - `git_status`: Query porcelain status, extract current branch, staged/unstaged/untracked file lists, clean flag.
  - `git_diff`: Compute git diff for working tree or staged changes with path filtering and statistics.
  - `git_commit`: Stage files, validate message (reject empty/whitespace-only), commit, and return commit hash.
  - `git_log`: Retrieve formatted commit history log.
  - Modular off-switch checking `locus.git_tools.enabled` and `locus.tools.git.enabled`.
  - Universal provider lifecycle (`initialize`, `health_check`, `shutdown`, `is_enabled`).
- Implement TypeScript client in `locus-extension/src/git-tools.ts` and re-export in `locus-extension/src/index.ts`.
- Register routes `/git/status`, `/git/diff`, `/git/commit`, `/git/log`, and `/git/config` in `sidecar/service.py` with 503 off-switch.
- Unit tests in `tests/unit/test_git_tools.py` and integration tests in `tests/integration/test_git_tools_service.py`.
- Pi table:
  - Need: Structured programmatic Git toolset (`git_status`, `git_diff`, `git_commit`, `git_log`) with safety boundaries, validation, and modular off-switch.
  - Pi mechanism: Pi provides raw shell command execution and basic Git URL parsing in `packages/coding-agent/src/utils/git.ts`, but lacks structured status parsing, diff analysis, commit validation, and HTTP endpoints.
  - What Locus adds: Dedicated `BaseGitToolsProvider` contract, porcelain status parser, diff metrics, validated commit creation, FastAPI `/git/*` service routes with 503 off-switch, and extension client wrapper.
  - Why Pi's is not enough: Pi's git utility is only a URL string parser without porcelain repository state inspection or commit guardrails.
