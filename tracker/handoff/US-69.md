# US-69 handoff - Gemini Flash, 2027-06-24

## Plan (written before coding)
- Implement `CwdJail`, `DEFAULT_BLOCKED_PATTERNS`, `PathValidationDecision`, `FileStateRecord`, and `FileStateTracker` in `sidecar/security/file_safety.py`.
- `cwd_jail`: Confines file operations to the project root and explicitly configured allowed paths; resolves realpaths, detects relative directory traversals (`../`), null byte injections, and attempts to access external filesystem hierarchies.
- `BLOCKED_PATTERNS`: Implements pattern safety layered on top of Pi's shell safety to protect git databases (`.git/`), credential files (`.env*`), private keys (`id_rsa`, `id_ed25519`, `*.pem`, `*.key`), and sensitive OS files (`/etc/shadow`, Windows `System32/SAM`).
- `file_state tracking`: Tracks file modifications across tool calls with timestamps, size in bytes, and SHA-256 hashes, persisted under `~/.locus/security/file_state.json`.
- Implement `BaseFileSafetyProvider` and `DefaultFileSafetyProvider` in `sidecar/providers/file_safety.py` with modular off-switches:
  - `locus.file_safety.enabled`
  - `locus.security.file_safety.enabled`
- Re-export symbols in `sidecar/security/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /security/file/validate`: validates paths against jail boundaries and blocked patterns.
  - `POST /security/file/record`: records file state change.
  - `GET /security/file/history`: retrieves modification history.
  - Off-switches returning HTTP 503 if disabled.
- Implement TypeScript contract `FileSafetyClient` in `locus-extension/src/security/file-safety.ts`.
- Write unit tests in `tests/unit/test_file_safety.py` and integration tests in `tests/integration/test_file_safety_service.py`.
- Pi table:
  - Need: Containment of file operations to project workspace and allowed directories (`cwd_jail`), protection of sensitive files from tool modifications, and cross-turn file state tracking.
  - Pi mechanism: Upstream Pi provides raw file read/write tools in `packages/coding-agent/src/index.ts` with no jail confinement or sensitive file pattern blocking.
  - What Locus adds: Full `CwdJail`, `FileStateTracker`, and `DEFAULT_BLOCKED_PATTERNS` engine in `sidecar/security/file_safety.py`, `sidecar/providers/file_safety.py`, and `locus-extension/src/security/file-safety.ts` with REST endpoints and 503 off-switch.
  - Why Pi's is not enough: Pi tools can inadvertently traverse to or overwrite parent directories, `.git/`, `.env`, or private key files without an explicit jail boundary guard.
