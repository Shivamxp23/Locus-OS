  - Official pricing database snapshot (USD per million tokens) for Anthropic, OpenAI, and Google Gemini models.
  - Four-provider canonical usage extraction (`anthropic`, `openai`, `google`/`gemini`, and Pi/generic).

  - Precise USD cost calculation: input tokens, output tokens, cache read tokens, cache write tokens, request cost.

- Register routes `/cost/calculate`, `/cost/record`, `/cost/session`, `/cost/pricing`, and `/cost/pricing/override` in `sidecar/service.py` with 503 off-switch on `locus.usage_cost_tracking.enabled`.
- Unit tests in `tests/unit/test_cost_tracker.py` and integration tests in `tests/integration/test_cost_tracker_service.py`.
- Pi table:
  - Need: Session-wide and daily token usage aggregation, official model pricing lookup, user pricing overrides, and USD cost accumulation per turn.
  - Pi mechanism: Pi emits basic usage metrics (`inputTokens`, `outputTokens`) on response events in packages/ai.
  - What Locus adds: Multi-provider raw response normalization into `CanonicalUsage` (prompt tokens, total tokens, cache reads/writes, reasoning tokens), official model pricing rates database snapshot, priority pricing chain, exact USD cost formulas, session and daily persistent accumulation, formatted TUI status strings, and modular off-switches.
  - Why Pi's is not enough: Pi does not maintain multi-day persistent cost databases, pricing lookup tables, cache/reasoning token differential pricing, or configurable cost-tracking off-switches.
