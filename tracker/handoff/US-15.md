## Config keys and defaults added
- `locus.vm.host`: remote VM host address/IP (default `127.0.0.1`).
- `locus.vm.user`: remote SSH username (default `ubuntu`).
- `locus.vm.ssh_port`: remote SSH port (default `22`).
- `locus.vm.sidecar_port`: remote VM sidecar port on loopback (default `8420`).
- `locus.vm.local_port`: local forward port on loopback (default `8420`).
- `locus.vm.ssh_key`: optional path to private SSH key.
