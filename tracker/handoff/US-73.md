# US-73 handoff - Gemini Flash, 2027-07-10

## Plan (written before coding)
- Implement `mask_token`, `SENSITIVE_QUERY_PARAMS`, `SENSITIVE_BODY_KEYS`, `KEY_PATTERNS`, and `DataRedactor` in `sidecar/security/redact.py`.
- `mask_token(token)`: Short tokens (<18 chars) fully masked (`***REDACTED***`); longer tokens preserve first 6 + last 4 characters (`token[:6] + "..." + token[-4:]`).
- `KEY_PATTERNS`: Implements vendor-specific API key scanning for OpenAI, Anthropic, Google, GitHub, Slack, AWS, Stripe, HuggingFace, JWT tokens, Bearer authorization, and PEM private keys.
- `SENSITIVE_QUERY_PARAMS` and `SENSITIVE_BODY_KEYS`: Masks sensitive fields in URL query strings and recursively scrubs nested dictionary/list JSON payloads while preserving non-sensitive data.
- Implement `BaseDataRedactionProvider` and `DefaultDataRedactionProvider` in `sidecar/providers/data_redaction.py` with modular off-switches:
  - `locus.data_redaction.enabled`
  - `locus.security.data_redaction.enabled`
  - `locus.security.redaction.enabled`
- Re-export symbols in `sidecar/security/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /security/redact/text`: scrubs credentials and query parameters from raw text strings.
  - `POST /security/redact/structure`: recursively scrubs sensitive keys and values from nested JSON structures.
  - `GET /security/redact/patterns`: lists active vendor and custom redaction patterns.
  - Returns HTTP 503 if any modular off-switch is disabled.
- Implement TypeScript contract and client `DataRedactionClient` in `locus-extension/src/security/redact.ts`, including `createAfterToolCallHook` to scrub secrets from tool output text before returning.
- Write unit tests in `tests/unit/test_data_redaction.py` and integration tests in `tests/integration/test_data_redaction_service.py`.
- Pi table:
  - Need: Scoped data redaction preventing leakage of sensitive credentials, API keys, tokens, and authorization parameters into logs, trajectory files, and external model responses.
  - Pi mechanism: Upstream Pi provides the hook `afterToolCall` in `packages/agent/src/types.ts:327`.
  - What Locus adds: Full regex-based `DataRedactor`, `DefaultDataRedactionProvider`, FastAPI routes, JSON structure walker, and TypeScript client contract with 503 off-switches.
  - Why Pi's is not enough: Upstream Pi returns raw tool outputs and unscrubbed strings without token masking or pattern-based redaction.
