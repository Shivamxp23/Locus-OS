## Plan (written before coding)
- Implement `BaseCustomLocusToolsProvider`, `CustomToolSpec`, `CustomToolResult`, and `CustomLocusToolsConfig` in `sidecar/providers/custom_locus_tools.py`.
- Re-export Custom Locus Tools provider contracts and types in `sidecar/providers/__init__.py`.
- Implement `CustomLocusToolsProvider` in `sidecar/custom_locus_tools.py`:
  - Registers the ~8 default Locus tools: `locus_checkin`, `locus_memory`, `locus_goals`, `locus_life`, `locus_vault`, `locus_brain`, `locus_research`, `locus_delegate_code`.
  - Schema definition and parameter validation for each tool.
  - Individual tool toggle support via `set_tool_enabled` / `is_tool_enabled` / `locus.tools.<name>.enabled`.
  - Execution dispatcher with error containment (catches handler exceptions and returns `CustomToolResult(success=False, error=...)`).
  - Swappability via `BaseCustomLocusToolsProvider` and dynamic tool registration.
- Implement TypeScript client and Pi bridge in `locus-extension/src/custom-locus-tools.ts`:
  - `CustomLocusToolsClient` supporting `listTools`, `getTool`, `executeTool`, `toggleTool`, `getConfig`, and `registerWithPi(pi)`.
  - Re-export in `locus-extension/src/index.ts`.
- Register routes in `sidecar/service.py`:
  - `/tools/custom/list`, `/tools/custom/config`, `/tools/custom/{tool_name}`, `/tools/custom/execute`, `/tools/custom/{tool_name}/toggle`
  - Off-switch returning 503 if `locus.custom_locus_tools.enabled` is False.
- Unit tests in `tests/unit/test_custom_locus_tools.py` and integration tests in `tests/integration/test_custom_locus_tools_service.py`.
- Pi table:
  - Need: Registration and execution of custom Locus domain tools with individual tool toggling and schema introspection.
  - Pi mechanism: Pi exposes a raw `pi.registerTool({ name, description, parameters, execute })` JavaScript API in `packages/coding-agent`.
  - What Locus adds: Locus adds a centralized provider layer (`BaseCustomLocusToolsProvider`), cross-language REST endpoints, individual runtime enable/disable toggles (`locus.tools.<name>.enabled`), error containment, and standard built-in cognitive tools (`locus_checkin`, `locus_memory`, `locus_goals`, `locus_life`, `locus_vault`, `locus_brain`, `locus_research`, `locus_delegate_code`).
  - Why Pi's is not enough: Pi does not have Python sidecar integration for custom tools, lacks dynamic per-tool config toggles at runtime, and does not provide out-of-the-box Life OS or memory stack tool implementations.
