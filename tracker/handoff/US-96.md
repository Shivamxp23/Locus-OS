## Plan
1. Implement `LocusShorthandCompressor`, `ShorthandCompressionResult`, `SHORTHAND_DICTIONARY`, and `SHORTHAND_DECODER_DICT` in `sidecar/compression/shorthand.py` per §27.3 (LOCUS_SHORTHAND 4× Text Compressor).
2. Deterministic regex compression pipeline:
   - Substitute transition words with dense mathematical symbols (because -> ∵, therefore -> ∴, approximately -> ≈, greater than -> >, less than -> <, and -> &, with -> w/, without -> w/o, which -> wh/, between -> b/w, regarding -> re:, for example -> e.g.).
   - Strip unambiguous grammatical articles (`the`, `a`, `an`).
   - Compact behavioral event stream representations (`{✓:...}`, `{→:...}`, `{e:...}`).
   - Provide decoder dictionary for system prompt prepending.
   - Reversible decompression back to human-readable form.
3. Support swappable / off state via `locus.compression.shorthand.enabled`: when disabled, text remains uncompressed.
4. Implement `DefaultShorthandCompressorProvider` in `sidecar/providers/shorthand.py` with modular off-switch `locus.locus_shorthand_4_text_compressor.enabled` returning HTTP 503.
5. Re-export provider in `sidecar/providers/__init__.py` and compression symbols in `sidecar/compression/__init__.py`.
6. Mount FastAPI routes in `sidecar/service.py`: `/compression/shorthand/compress`, `/compression/shorthand/decompress`, `/compression/shorthand/compress-event`, `/compression/shorthand/decoder`, `/compression/shorthand/status`.
7. Implement TypeScript client in `locus-extension/src/compression/shorthand.ts` and export from `locus-extension/src/compression/index.ts`.
8. Author unit tests (`tests/unit/test_locus_shorthand.py`) and integration tests (`tests/integration/test_shorthand_service.py`).
9. Update evidence in `tracker/features.yaml` for F-0122 and verify to Level 4 INTEGRATED (85%).
