## Plan
1. Implement `PageIndexEngine`, `PageIndexDoc`, `PageIndexNode`, and `PageIndexSearchResult` in `sidecar/search/pageindex.py` per §27.1 (Vectorless Retrieval - PageIndex).
2. Build hierarchical Markdown table-of-contents trees (`md_to_tree`):
   - Regex `#{1,6}` headers and standalone `**bold**` lines as level-1 headings, strictly skipping content inside fenced code blocks.
   - Text assignment between successive headers.
   - Cumulative token count per node bottom-up including all descendants.
   - Tree thinning for index compactness merging sub-threshold nodes into parents.
   - Stack-based nesting with zero-padded 4-digit node IDs ("0001", "0002", ...).
   - Summary and prefix_summary generation.
3. Reasoning-based tree search (`retrieve`): root-to-leaf traversal evaluating child summaries and returning leaf content with traceable citation path.
4. Support swappable / off state via `locus.retrieval.pageindex.enabled`.
5. Implement `DefaultPageIndexRetrievalProvider` in `sidecar/providers/pageindex.py` with modular off-switch `locus.pageindex_retrieval.enabled` returning HTTP 503.
6. Re-export provider in `sidecar/providers/__init__.py` and search symbols in `sidecar/search/__init__.py`.
7. Mount FastAPI routes in `sidecar/service.py`: `/pageindex/build-tree`, `/pageindex/retrieve`, `/pageindex/status`.
8. Implement TypeScript client in `locus-extension/src/search/pageindex.ts` and export from `locus-extension/src/search/index.ts`.
