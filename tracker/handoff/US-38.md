## Plan (written before coding)
- Implement `BaseImageGenerationProvider`, `ImageGenerationRequest`, `ImageGenerationResult`, and `ImageModelDescriptor` in `sidecar/providers/image_generation.py`.
- Re-export image generation contracts in `sidecar/providers/__init__.py`.
- Implement `ImageGenerationProvider` in `sidecar/image_generation.py`:
  - Catalog of standard models: `openai/dall-e-3`, `google/imagen-3.0`, `stability/sd3-turbo`, `black-forest-labs/flux-1.1-pro`.
  - Input validation: prompt non-empty/whitespace-only check; size normalization to model defaults.
  - Generates deterministic synthetic base64 image data for offline test stability.
  - Modular off-switch checking `locus.image_generation.enabled` and `locus.images.enabled`.
  - Register provider in registry under `("image_generation", "default", ImageGenerationProvider)` and `("images", "default", ImageGenerationProvider)`.
- Implement TypeScript extension client in `locus-extension/src/image-generation.ts` and re-export in `locus-extension/src/index.ts`.
- Register routes `/images/generate`, `/images/models`, and `/images/config` in `sidecar/service.py` with 503 off-switch.
- Unit tests in `tests/unit/test_image_generation.py` and integration tests in `tests/integration/test_image_generation_service.py`.
- Pi table:
  - Need: Model-driven image generation API and extension client supporting multi-provider catalogs (DALL-E, Imagen, SD3, Flux) with size validation and modular off-switch.
  - Pi mechanism: Pi defines static image catalog types in `packages/ai/src/image-models.ts`, but does not provide an active sidecar REST endpoint, request validation, base64 payload response framing, or modular off-switch.
  - What Locus adds: Standardized `BaseImageGenerationProvider` contract, FastAPI `/images/*` service endpoints, modular 503 off-switch on `locus.image_generation.enabled`, prompt/size validation, and extension client.
  - Why Pi's is not enough: Pi's catalog is a static compile-time read without an HTTP service bridge or runtime off-switch for web clients and sidecar tools.
