# US-04 handoff - Gemini, 2026-10-15

## Plan (written before coding)
1. Implement `sidecar/telegram_pairing.py` with `TelegramPairingManager` enforcing S-1 fail-closed security.
2. Generate single-use pairing codes of >= 8 unambiguous uppercase characters using `secrets.choice`, active for 10 minutes (600s).
3. Store only the SHA-256 hash of the active pairing code in memory; destroy the code immediately upon successful pairing.
4. Enforce lockout: 5 wrong pairing attempts lock pairing for 15 minutes (900s).
5. On successful `/pair <code>`, save numeric Telegram user ID to `LOCUS_HOME/config.yaml` under `locus.channels.telegram.allowed_user_ids`.
6. Refuse all messages from non-direct sources (group chats, forwards, channels).
7. Until paired, return fixed string `"Locus is not configured."` and execute nothing.
8. If the allow-list cannot be read or written, fail closed (refuse all messages).
9. Refuse webhook mode if `TELEGRAM_WEBHOOK_SECRET` is unset or empty.
10. Write comprehensive unit test suite in `tests/test_telegram_pairing.py` covering all six mandatory S-1 tests plus code expiration and webhook checks.
11. Add evidence to `tracker/features.yaml` under `F-0083` and verify Level 3 (`UNIT_VERIFIED`).
12. Run full guard checks and deterministic tracker verification and export.
