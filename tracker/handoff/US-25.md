## Security (anything found, even if outside this story)
- Cached original messages in `.locus/headroom_cache/` are stored on local loopback filesystem with SHA-256 hashed keys; no plaintext message leakage outside user workspace.
- CCR endpoints bind strictly to loopback (`127.0.0.1`), never `0.0.0.0`.
- All endpoints enforce the 503 kill-switch when disabled.
