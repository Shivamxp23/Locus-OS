## Plan (written before coding)
- Implement `format_notification_message` and `dispatch_job_notification` in `sidecar/cron_runner.py` to deliver finished research job outputs to the paired owner via the registered `ChannelProvider`.
- Check `job.notify` toggle (default True); when disabled, skip channel delivery.
- Format message with job title, status, timestamp, and output text body.
- Resolve paired owner chat ID from channel pairing manager (`channel.pairing_manager.get_allowed_user_ids()`) or configuration.
- Support chunked delivery for outputs exceeding 4096 characters via `chunk_message` without truncation.
- Ensure delivery errors or missing channels do not crash the runner; capture errors in run log `error` column.
- Write unit and integration tests in `tests/test_deliver_result.py`.
- Update `tracker/features.yaml` under `F-0046` with test evidence.
