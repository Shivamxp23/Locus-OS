## Plan (written before coding)
- Implement `ContextRefType` Enum (`@file`, `@dir`, `@symbol`, `@git`, `@diff`, `@url`) and `ResolvedReference` dataclass in `sidecar/context/references.py`.
- Implement regex parser `PATTERN = r"(@(file|dir|symbol|git|diff|url):([^\s\n]+))"` and path/line parser `parse_path_and_lines(target)`.
- Implement `ContextReferenceResolver.extract_and_resolve_references(user_prompt, max_ref_budget)`:
  - Resolves `@file:path#L10-L45` with line extraction and token budget truncation.
  - Resolves `@dir:path/` directory listing.
  - Resolves `@symbol:name` via AST traversal over repository Python source files.
  - Resolves `@git:status`, `@git:diff`, `@git:<branch>`.
  - Resolves `@diff:unstaged`.
  - Resolves `@url:https://...`.
  - Replaces tag with `[{REF_KIND}: {target}]`.
- Implement `format_references_xml(refs)` formatting into `<context_ref type="..." target="...">...</context_ref>` enclosures.
- Implement `BaseContextReferenceProvider` and `DefaultContextReferenceProvider` in `sidecar/providers/context_references.py` with modular off-switch (`locus.context_references.enabled` and `locus.context.references.enabled`). Off state treats tags as literal text without resolution.
- Re-export symbols in `sidecar/context/__init__.py` and `sidecar/providers/__init__.py`.
- Implement TypeScript contract in `locus-extension/src/context/references.ts`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `GET /context/references/config`
  - `POST /context/references/resolve`
  - `POST /context/references/format-xml`
  - Modular off-switch returning HTTP 503 if `locus.context_references.enabled` or `locus.context.references.enabled` is False.
- Write unit tests in `tests/unit/test_context_references.py` and integration tests in `tests/integration/test_context_references_service.py`.
- Pi table:
  - Need: Dynamic inline prompt context reference tags (`@file`, `@dir`, `@symbol`, `@git`, `@diff`, `@url`) with budget-bounded extraction and structured XML enclosure.
  - Pi mechanism: Pi has interactive CLI file reference completion in `packages/coding-agent/src/modes/interactive/` but no sidecar HTTP resolution API, no AST symbol resolver, and no `<context_ref>` XML formatting layer for headless/remote agents.
  - What Locus adds: Full Python sidecar `ContextReferenceResolver` supporting multi-source resolution, token budget truncation, AST symbol lookup, `<context_ref>` XML enclosure formatter, and FastAPI endpoints with 503 off-switch.
  - Why Pi's is not enough: Remote headless runners (e.g. Telegram bridge, research scheduler) cannot interactively resolve client-side references without an explicit server-side reference resolver engine.
