- Build `sidecar/scheduler.py` implementing `SchedulerProvider` abstract interface and `APSchedulerProvider` concrete provider registered in the universal provider registry (`get_registry().register('scheduler', 'apscheduler', APSchedulerProvider, is_default=True)`).

- Extend `sidecar/cron_runner.py` with `run_research_job()`:
  - Invokes `execute_cron_job(job.id, job.prompt)` -> `run_pi_turn(session_id='cron_<job_id>')`.
  - Writes research output to vault destination (e.g. `vault/05-Daily/Research/YYYY-MM-DD-<name>.md`) with YAML frontmatter (`title`, `date`, `source: locus-scheduler`, `job_id`, `tags`).

- Enforce feature toggle `locus.scheduler.enabled`: when disabled, background scheduler does not start and jobs fail-closed without invoking Pi.
- Add unit tests in `tests/test_scheduler.py`, modularity tests in `tests/test_scheduler_modular.py`, and full integration test in `tests/test_scheduler_integration.py`.
- Update `tracker/features.yaml` under `F-0058` with real evidence files, symbols, unit, and integration tests.
