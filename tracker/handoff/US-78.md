# US-78 handoff - Gemini Flash, 2027-07-30

## Plan (written before coding)
- Implement Browser Automation engine and provider interfaces in `sidecar/browser/automation.py`:
  - `BaseBrowserEngine`: abstract interface for browser drivers (`navigate`, `click`, `type_text`, `screenshot`, `content`, `close`).
  - `PlaywrightBrowserProvider`: default local headless browser engine.
  - `BrowserbaseProvider`: remote cloud browser provider via Browserbase API.
  - `MockBrowserProvider`: deterministic offline fixture for unit and integration testing.
  - `UIElement`, `BrowserTask`, and `BrowserResult` data structures.
- Implement Screen Intelligence in `sidecar/browser/screen_intelligence.py`:
  - `ScreenIntelligence`: inspects screenshots and identifies interactive UI elements (buttons, links, text fields, dropdowns, checkboxes) with bounding coordinates.
- Implement `BrowserAutomationManager` in `sidecar/browser/manager.py`:
  - Orchestrates browser sessions, provider switching, screen intelligence, and multi-step automated task flows (`automate_task`).
- Implement `BaseBrowserProvider` and `DefaultBrowserProvider` in `sidecar/providers/browser.py` with modular off-switches:
  - `locus.browser.enabled`
  - `locus.browser_automation.enabled`
- Re-export symbols in `sidecar/browser/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /browser/navigate`: navigates to target URL.
  - `POST /browser/click`: simulates mouse clicks by selector or coordinates.
  - `POST /browser/type`: simulates keyboard input.
  - `POST /browser/screenshot`: captures PNG screenshot.
  - `POST /browser/analyze`: analyzes screen elements via Screen Intelligence.
  - `POST /browser/automate`: executes automated task flows.
  - `GET /browser/providers`: lists available browser engines.
  - Returns HTTP 503 when disabled.
- Implement TypeScript client contract in `locus-extension/src/browser/browser.ts`.
- Write unit tests in `tests/unit/test_browser_automation.py` and integration tests in `tests/integration/test_browser_service.py`.
- Pi table:
  - Need: Headless browser automation, element identification, and screen intelligence workflows for web exploration and automated data retrieval.
  - Pi mechanism: Upstream Pi provides coding and terminal agent loops without native browser drivers or visual screen intelligence.
  - What Locus adds: Multi-engine browser automation (`sidecar/browser/`), `BrowserAutomationManager`, `ScreenIntelligence`, FastAPI endpoints, and TypeScript client contract with 503 off-switches.
  - Why Pi's is not enough: Upstream Pi cannot navigate websites, capture rendered page screenshots, or click/type into interactive DOM elements.

- Engine abstraction enables safe sandboxing and mock execution without uncontrolled network ingress.
