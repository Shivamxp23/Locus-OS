# US-76 handoff - Gemini Flash, 2027-07-22

## Plan (written before coding)
- Implement Speech-to-Text (STT) providers in `sidecar/voice/stt.py`:
  - `BaseSTTProvider`: abstract provider interface with `transcribe(audio_bytes, language, model)`.
  - `GroqWhisperSTTProvider`: default, fastest, free tier STT using `whisper-large-v3-turbo` with offline fallback.
  - `WhisperLocalSTTProvider`: local STT engine.
  - `OpenAISTTProvider`: whisper-1 provider.
  - `AzureSTTProvider`: cloud speech provider.
  - `MockSTTProvider`: deterministic testing and fixture provider.
- Implement Text-to-Speech (TTS) providers in `sidecar/voice/tts.py`:
  - `BaseTTSProvider`: abstract provider interface with `synthesize(text, voice)` and `list_voices()`.
  - `EdgeTTSProvider`: default, high quality, free, no API key required, defaulting to `en-US-GuyNeural`.
  - `ElevenLabsTTSProvider`: realistic neural TTS provider.
  - `PiperTTSProvider`: local lightweight neural TTS.
  - `OpenAITTSProvider`: tts-1 / tts-1-hd provider.
  - `MockTTSProvider`: deterministic testing provider.
- Implement `VoicePipelineManager` in `sidecar/voice/pipeline.py`:
  - Manages active STT and TTS providers with runtime hot-swapping.
  - Implements the Telegram Voice Message Flow (Audio → STT → Process → TTS → Audio).
- Implement `BaseVoiceProvider` and `DefaultVoiceProvider` in `sidecar/providers/voice.py` with modular off-switches:
  - `locus.voice.enabled`
  - `locus.stt.enabled`
  - `locus.tts.enabled`
- Re-export symbols in `sidecar/voice/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /voice/stt/transcribe`: transcribes base64 audio.
  - `POST /voice/tts/synthesize`: synthesizes text to base64 audio.
  - `POST /voice/process_message`: executes full Telegram message loop.
  - `GET /voice/providers`: returns registered providers and defaults.
  - `GET /voice/voices`: returns available voices.
  - Returns HTTP 503 when disabled.
- Implement TypeScript client contract in `locus-extension/src/voice/voice.ts`.
- Write unit tests in `tests/unit/test_voice_pipeline.py` and integration tests in `tests/integration/test_voice_service.py`.
- Pi table:
  - Need: Voice transcription (STT) and voice synthesis (TTS) supporting fast interactive conversational workflows (Telegram, desktop dictation, speech responses).
  - Pi mechanism: Upstream Pi provides raw agent turn loops without multi-provider speech audio processing or streaming speech adapters.
  - What Locus adds: Multi-provider STT/TTS engine (`GroqWhisper`, `EdgeTTS`, `WhisperLocal`, `ElevenLabs`, `Piper`, `OpenAI`), `VoicePipelineManager`, Telegram voice message pipeline, FastAPI endpoints, and TypeScript client.
  - Why Pi's is not enough: Upstream Pi has no audio processing pipeline, no STT transcription models, and no TTS voice synthesis capabilities.

## Security (anything found, even if outside this story)
- Audio transcription and synthesis requests accept base64 payloads to ensure binary neutrality over JSON HTTP transports.
- Free tier defaults (`GroqWhisper` and `EdgeTTS`) operate without mandatory cloud subscription keys, preventing hardcoded secret leaks.
- Modular off-switches (`locus.voice.enabled`, `locus.stt.enabled`, `locus.tts.enabled`) return HTTP 503 with standardized status payloads.
