# US-05 handoff - Gemini, 2026-10-15

## Plan (written before coding)
1. Implement canonical configuration accessor in `sidecar/config.py` defining `get(path, default=None)` and `is_enabled(path)`.
2. Implement identical configuration accessor in `locus-extension/src/config.ts` defining `get(dotPath, defaultValue=null)` and `is_enabled(dotPath)`.
3. Support dot-separated key traversal (e.g. `locus.demo.value`), missing key fallback to default, and environment variable access via `env.<VAR>` or `get_env()`.
4. Implement CLI interface in `sidecar/config.py`: `python -m sidecar.config get <path> [<default>]`.
5. Update `sidecar/pi_bridge.py` and `sidecar/telegram_pairing.py` to route environment/path lookups through `sidecar.config`.
6. Enforce that no module outside the accessor reads `os.environ`, `process.env`, or the configuration file directly.
7. Implement unit tests in `tests/test_config_accessor.py` verifying Python and TypeScript accessors, CLI, and absence of direct environment reads.
8. Register evidence in `tracker/features.yaml` under `F-0125` and verify Level 3 (`UNIT_VERIFIED`).
9. Run full guard checks and deterministic tracker verification and export.
