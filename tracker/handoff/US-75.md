# US-75 handoff - Gemini Flash, 2027-07-18

## Plan (written before coding)
- Implement `SURROGATE_RE`, `sanitize_surrogates`, `sanitize_structure_surrogates`, `sanitize_messages`, and `MessageSanitizer` in `sidecar/security/sanitizer.py`.
- `sanitize_surrogates(text)`: scans for lone surrogate code points (`[\ud800-\udfff]`) that cause `json.dumps()` and UTF-8 encoding crashes in LLM client SDKs, replacing them with Unicode replacement character `\ufffd` while returning clean strings untouched.
- `sanitize_structure_surrogates(payload)`: recursively walks nested dictionaries and lists (e.g. `reasoning_details`, tool results, metadata) and sanitizes surrogate strings, returning `(sanitized, found_surrogates)`.
- `sanitize_messages(messages)`: applies full sanitization to `content`, `tool_calls`, and structured metadata across message arrays before API dispatch.
- Implement `BaseMessageSanitizerProvider` and `DefaultMessageSanitizerProvider` in `sidecar/providers/message_sanitizer.py` with modular off-switches:
  - `locus.message_sanitization.enabled`
  - `locus.security.message_sanitization.enabled`
- Re-export symbols in `sidecar/security/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /security/sanitize/text`: sanitizes lone surrogates from strings.
  - `POST /security/sanitize/structure`: recursively sanitizes nested JSON dictionaries and lists.
  - `POST /security/sanitize/messages`: sanitizes message lists before sending to LLM.
  - Returns HTTP 503 when disabled.
- Implement TypeScript client and stateless helpers in `locus-extension/src/security/message-sanitize.ts`.
- Write unit tests in `tests/unit/test_message_sanitizer.py` and integration tests in `tests/integration/test_message_sanitizer_service.py`.
- Pi table:
  - Need: Stateless surrogate code point sanitization preventing fatal Unicode UTF-8 encoding exceptions during JSON serialization and API dispatch.
  - Pi mechanism: Upstream Pi provides `convertToLlm` hook in `packages/agent/src/types.ts`.
  - What Locus adds: Full `MessageSanitizer`, `DefaultMessageSanitizerProvider`, recursive structure walker, FastAPI endpoints, and TypeScript contract with 503 off-switches.
  - Why Pi's is not enough: Upstream Pi passes message payloads directly to API client serialization without filtering lone surrogates or deep-sanitizing tool call arguments.
