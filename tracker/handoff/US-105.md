## Config keys
- `locus.notifications.enabled`: Master toggle for Notifications provider (default true, returns HTTP 503 when off).
- `notifications.quiet_hours`: Configuration dictionary for quiet hours interval (`start_hour`, `start_minute`, `end_hour`, `end_minute`).
- `notifications.primary_channel`: Primary delivery channel for MEDIUM notifications (default `telegram`).
- `locus.state.dcs`: Current DCS cognitive stress score (values < 3.0 trigger non-HIGH suppression).
- `locus.notifications.channels.<name>.enabled`: Per-channel toggle.
