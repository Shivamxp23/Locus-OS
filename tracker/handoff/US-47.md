# US-47 handoff - Gemini 3.8 Flash, 2026-10-20

## Plan (written before coding)
- Implement `TreeNode`, `TreeScopeConfig`, `MemoryTreeConfig`, and `BaseMemoryTreeProvider` in `sidecar/providers/memory_tree.py`.
- Re-export Memory Tree provider contracts and types in `sidecar/providers/__init__.py`.
- Implement `HierarchicalMemoryTreeProvider` in `sidecar/memory_tree.py`:
  - L0 leaf buffer appending with SQLite persistence (`mem_tree_chunks`, `mem_tree_ingested_sources`).
  - Automatic seal gate trigger (threshold of N items, default 8).
  - Progressive summarization cascade (L0 -> L1 -> LN -> Root).
  - Time-based stale flush (if L0 buffer age > 3 hours, seal regardless of count).
  - Top-down relevance search descending into relevant tree branches and weighting summaries.
  - Topic routing cross-tree distribution into `topic:<name>` scopes.
  - Health check reporting chunk counts, unsealed items, and max depth.
- Implement TypeScript client `MemoryTreeClient` in `locus-extension/src/memory-tree.ts` and re-export in `locus-extension/src/index.ts`.
- Register routes in `sidecar/service.py`:
  - `GET /memory/tree/config`, `GET /memory/tree/nodes`, `GET /memory/tree/search`, `POST /memory/tree/leaf`, `POST /memory/tree/seal`, `POST /memory/tree/topic_route`.
  - Modular off-switch returning 503 if `locus.memory_tree_hierarchical_summarization_cascade.enabled` (or `locus.memory.tree.enabled`) is False.
- Unit tests in `tests/unit/test_memory_tree.py` and integration tests in `tests/integration/test_memory_tree_service.py`.
- Pi table:
  - Need: Structured hierarchical memory tree over text corpora with deterministic bucket-sealing and multi-level summarization.
  - Pi mechanism: Pi has no tree memory or progressive summarization cascade; only flat session message history and basic raw text retrieval.
  - What Locus adds: Multi-level summarization tree (L0 buffer -> L1-LN summaries -> Root) with automatic upward seal cascades, topic routing, stale flush timers, and SQLite backing.
  - Why Pi's is not enough: Flat message histories grow monotonically, hit context limits, cannot provide multi-resolution executive-to-leaf drilldowns, and cannot organize notes by persistent topics.
