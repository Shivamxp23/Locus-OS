# US-79 handoff - Gemini Flash, 2027-08-03

## Plan (written before coding)
- Implement Desktop Screen Capture provider in `sidecar/screen/capture.py`:
  - `BaseScreenCaptureProvider`: abstract interface for screen capture backends (`capture_display`, `capture_region`, `capture_window`).
  - `DesktopScreenCaptureProvider`: native OS screen capture using PIL.ImageGrab with graceful headless fallback.
  - `MockScreenCaptureProvider`: deterministic synthetic capture returning 1920x1080 test frame.
  - `ScreenCaptureResult`: structured capture outcome with base64 PNG data, dimensions, display id, and metadata.
- Implement Native Desktop Control in `sidecar/screen/desktop_control.py`:
  - `BaseDesktopController`: abstract interface for mouse, keyboard, and window control.
  - `NativeDesktopController`: native OS controller using pyautogui with fallback.
  - `MockDesktopController`: deterministic mock recording actions and producing synthetic responses.
  - `DesktopAction` and `DesktopActionResult`: action dispatch payloads.
- Implement Screen Intelligence in `sidecar/screen/screen_intelligence.py`:
  - `ScreenIntelligence`: vision and heuristic element identifier returning buttons, links, text fields, dropdowns, checkboxes with bounding coordinates and center points.
- Implement `ComputerUseManager` in `sidecar/screen/manager.py`:
  - Orchestrates screen capture, screen analysis, desktop actions, element clicking by id, and multi-action workflows (`execute_workflow`).
- Implement `BaseScreenProvider` and `DefaultScreenProvider` in `sidecar/providers/screen.py` with modular off-switches:
  - `locus.screen.enabled`
  - `locus.computer_use.enabled`
  - `locus.desktop_control.enabled`
- Re-export symbols in `sidecar/screen/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /screen/capture`: capture screen display, region, or window.
  - `POST /screen/control`: execute native desktop action (click, type, window_focus).
  - `POST /screen/analyze`: identify interactive UI elements on screen.
  - `POST /screen/execute`: execute multi-action computer use workflow.
  - `GET /screen/status`: return provider availability and backends.
  - Returns HTTP 503 when disabled.
- Implement TypeScript client contract in `locus-extension/src/screen/screen.ts`.
- Write unit tests in `tests/unit/test_screen_computer_use.py` and integration tests in `tests/integration/test_screen_service.py`.
- Pi table:
  - Need: Desktop computer use, screen capture, element identification, and desktop companion automation for autonomous workflows.
  - Pi mechanism: Upstream Pi provides code editing and terminal interaction without native screen capture or OS desktop companion capabilities.
  - What Locus adds: Multi-backend screen capture (`sidecar/screen/capture.py`), native desktop control (`sidecar/screen/desktop_control.py`), screen intelligence (`sidecar/screen/screen_intelligence.py`), `ComputerUseManager`, FastAPI endpoints, and TypeScript client contract with 503 off-switches.
  - Why Pi's is not enough: Upstream Pi cannot capture user display frames, locate interactive GUI elements, or send synthetic OS mouse/keyboard events.
