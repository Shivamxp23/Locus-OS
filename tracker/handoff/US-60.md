## Security (anything found, even if outside this story)
- Git command executions use parameterized argument lists (`["git", "diff", "--stat"]`) avoiding shell injection vulnerabilities.
- Diff outputs are bounded by token budgets to prevent prompt injection or memory exhaustion.

## Not done (be specific; "nothing" is almost never true)
- Tree-sitter native C-bindings parser is not bundled; standard library `ast` is used for Python and optimized regex scanners for TypeScript/JavaScript. Tree-sitter grammar extensions for other languages (Rust, Go) can be wired as plugins.
