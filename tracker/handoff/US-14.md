# US-14 handoff - Claude 3.5 Sonnet, 2026-11-16

## Plan (written before coding)
- Implement `sidecar/telegram/secret_manager.py`:
  - `SecretReference`: holds opaque token, provider name, creation timestamp, and consumption flag; provides 5-minute timeout check (`is_expired`) and 15-minute cleanup check (`is_cleanable`).
  - `SecretReferenceManager`: manages token lifecycle, generates 16-byte hex tokens, consumes references by safely writing keys to `LOCUS_HOME/.env` (mode 0600), and cleans up expired sessions.
- Update `sidecar/telegram/gateway.py`:
  - Integrate `SecretReferenceManager`.
  - Add `delete_message(chat_id, message_id)` to request Telegram message deletion for secrets.
  - In `handle_update`:
    - Handle `/setup <provider>`: generates opaque secret reference and responds with usage instructions.
    - Handle `/secret <ref_token> <api_key>`: immediately triggers message deletion, validates and consumes the reference, persists the key into `.env`, and returns a safe response (never echoing the secret).
    - Handle unpaired user: returns fixed line `"not configured"` and deletes any potential secrets sent via `/secret`.
- Update `locus_cli/install.py`:
  - Add `prompt_telegram_pairing` helper to trigger pairing code generation.
  - Support `--reconfigure telegram` and `--reconfigure pairing`.
- Add tests in `tests/unit/test_telegram_setup.py`:
  - Verify installer pairing trigger.
  - Verify `/setup` token issuance and formatting.
  - Verify 5-minute timeout rejection and 15-minute memory cleanup.
  - Verify message deletion call, key persistence in `.env`, and refusal of token reuse.
  - Verify unpaired stranger rejection.
