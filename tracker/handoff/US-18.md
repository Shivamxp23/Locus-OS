## Plan (written before coding)
- Implement `sidecar/providers/chat_archiver.py`:
  - `BaseChatArchiverProvider` abstract interface declaring `crawl_and_parse()`, `archive_chat()`, and `archive_all()`.
  - Data transfer types: `ChatTurn`, `NormalizedChat`, `ArchiveResult`.
- Implement `sidecar/crawlers/chat_crawler.py`:
  - `ChatCrawler` scanning export directories for `.json`, `.jsonl`, `.md`, `.txt` dumps.
  - Multi-platform parsers:
    - ChatGPT export mapping trees.
    - Claude Web/App chat message dumps.
    - Cursor IDE conversation logs.
    - Pi native sessions.
    - Telegram exported chat history.
  - Regex-based key decision extraction (`extract_key_decisions`).
- Implement `sidecar/ingestion/chat_archiver.py`:
  - `ChatArchiverProvider` implementing `BaseChatArchiverProvider`.
  - Obsidian markdown formatting with YAML frontmatter (title, date, platform, model, tags, summary).
  - Key decision bullet points and transcript sections.
  - Vault persistence under `04-Captures/AI Chats/YYYY-MM-DD/{title}.md`.
  - Automated CouchDB LiveSync push notification on write.
  - Modular off-switch checking `locus.ingestion.chat_archiver.enabled`.
- Update `sidecar/service.py`:
  - Register `/ingestion/chats/crawl` and `/ingestion/chats/archive` endpoints.
  - Modular off-switch returning 503 `{"disabled": "locus.ingestion.chat_archiver.enabled"}` when disabled per SPEC §03 line 35.
- Tests in `tests/unit/test_chat_archiver.py` and `tests/integration/test_chat_archiver_service.py`:
  - Unit tests for interface adherence, platform parsers (ChatGPT, Claude, Cursor, Pi, Telegram), decision extraction, frontmatter formatting, vault writing, LiveSync hook, off-switch, and modular swap.
  - Integration tests for FastAPI HTTP routes and off-switch 503 response.
