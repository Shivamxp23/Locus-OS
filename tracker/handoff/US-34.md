- Pi table:
  - Need: 6-layer dynamic context assembly right before LLM turn generation with unified relevance scoring, multi-tier layer token limits, Hebbian edge weight signaling, and anti-hallucination instructions.
  - Pi mechanism: Pi has `transformContext` hook and static prompt construction, but lacks structured multi-layer budgeting, Hebbian graph signal updates, CCR headroom compression fallback, or multi-modal database retrieval consolidation.
  - What Locus adds: Canonical 6-layer assembler with independent layer budgets (Identity 80t, Temporal 60t, Events 180t, Neo4j 150t, pgvector 200t, Web 100t; 800t total headroom limit), Hebbian edge increments (+0.1), anti-hallucination guard instructions, and modular 503 off-switch.
  - Why Pi's is not enough: Pi passes unstructured conversational history without biological state, short-term shorthand events, or knowledge-graph pathway traversal reinforcement.
