# US-81 handoff - Gemini Flash, 2027-08-11

## Plan
1. Dual-transport MCP Client (stdio + Streamable HTTP) with tool description sanitization (`sidecar/mcp/client.py`, `sidecar/mcp/sanitize.py`).
2. MCP Server Registry and lifecycle supervisor with exponential backoff and opaque secret ref management (`sidecar/mcp/registry.py`).
3. Locus MCP Server JSON-RPC 2.0 dispatch with version negotiation, argument validation, and write audit pipeline (`sidecar/mcp/server.py`).
4. Provider registration in `sidecar/providers/mcp.py` with modular off-switches returning HTTP 503 (`locus.mcp_server_client.enabled` and `locus.mcp.enabled`).
5. Mounted routes on FastAPI sidecar (`sidecar/service.py`): `/mcp/servers/connect`, `/mcp/servers/disconnect`, `/mcp/servers/list`, `/mcp/tools/list`, `/mcp/tools/call`, `/mcp/server/jsonrpc`, `/mcp/status`.
6. Extension TypeScript contracts in `locus-extension/src/mcp/`.
7. Unit tests in `tests/unit/test_mcp_server_client.py` and integration tests in `tests/integration/test_mcp_service.py`.

Pi table:
- Need: Transport-neutral MCP client, dynamic server registry with backoff reconnection, tool description sanitization against prompt injection, Locus-as-MCP-server host, and provider modular off-switches.
- Pi mechanism: `packages/mcp/src/client.ts` (`McpClient`, `StdioTransport`, `StreamableHttpTransport`).
- What Locus adds: Dynamic multi-server registry, 60s supervisor reconnection loop, prompt injection description sanitizer, JSON-RPC 2.0 Locus server endpoint with write audit logging, and sidecar REST provider with modular 503 off-switches.
- Why Pi is not enough: Pi provides a standalone TypeScript client without multi-server registry management, backoff reconnection supervisor, prompt sanitization filter, server write audit logging, Python sidecar provider, or modular HTTP 503 off-switches.

- Tool descriptions from external untrusted MCP servers are aggressively sanitized to strip control characters and instruction fences (`sanitize_for_llm`).
- Opaque secret references (`secret://<uuid>`) prevent leaking raw credentials into LLM context during setup.
- Write operations on Locus MCP server are captured in an explicit audit pipeline with truncated, privacy-redacted arguments.
- Modular off-switches return HTTP 503.
