# US-71 handoff - Gemini Flash, 2027-07-02

## Plan (written before coding)
- Implement `ApprovalStatus`, `ApprovalRequest`, and `ApprovalStore` in `sidecar/security/approval_store.py`.
- `queue_approval`: records requests with changes, pending status, created epoch, and 10-minute default TTL expiration.
- `resolve_approval`: updates pending requests to approved or rejected status with actor metadata.
- `wait_for_approval`: synchronously or asynchronously polls status until resolved or TTL expires (auto-reject).
- Ensure approval state is purely runtime in-memory and never written to `.locus` or disk to protect sensitive action parameters.
- Implement `BaseApprovalGateProvider` and `DefaultApprovalGateProvider` in `sidecar/providers/approval_gate.py` with modular off-switches:
  - `locus.approval_gate.enabled`
  - `locus.security.approval_gate.enabled`
- Re-export symbols in `sidecar/security/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /security/approval/request`: queues new approval request.
  - `GET /security/approval/status`: gets current approval status and enforces TTL check.
  - `POST /security/approval/resolve`: approves or denies a pending approval.
  - `POST /security/approval/wait`: waits for approval with configurable timeout.
  - `GET /security/approval/pending`: lists active unexpired pending requests.
  - Off-switches returning HTTP 503 if disabled.
- Implement TypeScript contract `ApprovalGateClient` in `locus-extension/src/security/approval-gate.ts`, with `createApprovalProvider` connecting directly to `AutonomyTiersClient.createBeforeToolCallHook`.
- Write unit tests in `tests/unit/test_approval_gate.py` and integration tests in `tests/integration/test_approval_gate_service.py`.
- Pi table:
  - Need: Runtime approval gating with 10-minute TTL, queueing approval requests, interactive resolution, and automatic auto-reject timeout fallback.
  - Pi mechanism: Upstream Pi provides the raw hook interface `beforeToolCall` in `packages/agent/src/types.ts:326`.
  - What Locus adds: Full in-memory `ApprovalStore` with TTL expiration, `DefaultApprovalGateProvider`, FastAPI endpoints, and TypeScript `ApprovalGateClient` with 503 off-switch.
  - Why Pi's is not enough: Pi does not manage asynchronous approval queues or interactive user confirmation lifecycles.

- Approval state is kept purely in-memory at runtime to prevent leaking sensitive command arguments or proposed file diffs to disk.
- TTL enforcement runs both eagerly on access and as a hard cutoff during polling: expired requests automatically transition to `expired` status and reject execution.
- Modular off-switches return HTTP 503 with standardized error metadata.
