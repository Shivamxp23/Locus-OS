## Plan (written before coding)
- Implement `sidecar/providers/life_os.py`:
  - `BaseLifeOSProvider` abstract interface declaring `calculate_tws()`, `calculate_dcs()`, `resolve_mode()`, and `compute_faction_lag()`.
  - Data transfer types: `GoalStackLevel`, `FactionType`, `OperatingMode`, `ModeConstraints`, `TaskScoreInput`, `TaskScoreResult`, `CheckInInput`, `DCSResult`, `PostTaskLog`.
- Implement `sidecar/life_os/tws.py`:
  - `calculate_tws()` implementing D-1 Option A: `(P * 0.4) + (U * 0.4) + (D * 0.2)` with inputs clamped 1-10.
  - Lag bonus: `>3h -> +2`, `>6h -> +4`, `ahead -> -1`.
  - Multi-scale roll-up (D-3 Option a): combines constituent child scores for Milestone and Vision goals.
  - `log_post_task()`: enforces explanation if actual time deviates >50% from estimate.
- Implement `sidecar/life_os/dcs.py`:
  - `calculate_dcs()` implementing `((E + M + S)/3) * (1 - ST/20)`.
  - Staleness penalty: misses 1-2 days -> score * 0.9.
  - Missing 3+ days -> default to baseline (5, 5, 5, 7) yielding DCS 3.25 and alert `STALE_CHECKIN`.
- Implement `sidecar/life_os/modes.py`:
  - 5 Operating Modes: SURVIVAL (0.0-2.0), RECOVERY (2.1-4.0), NORMAL (4.1-6.0), DEEP WORK (6.1-8.0), PEAK (8.1-10.0).
  - Mode constraints specifying max difficulty threshold and discretionary task caps.
- Implement `sidecar/life_os/factions.py`:
  - 4 Factions: Health/Stability (25%), Leverage/Money (25%), Craft/Skills (30%), Expression/Explore (20%).
  - Crisis hierarchy: Health > Leverage > Craft > Expression.
  - `compute_faction_lag()`: target hours minus actual logged hours.
- Implement `sidecar/life_os/provider.py` and `sidecar/life_os.py`:
  - `LifeOSProvider` implementing `BaseLifeOSProvider` with universal provider pattern (`initialize`, `health_check`, `shutdown`).
- Update `sidecar/service.py`:
  - Register `/life_os/tws`, `/life_os/dcs`, and `/life_os/mode` endpoints.
  - Modular off-switch returning 503 `{"disabled": "locus.life_os.enabled"}` when disabled per SPEC §03 line 35.
- Tests in `tests/unit/test_life_os.py` and `tests/integration/test_life_os_service.py`:
  - Unit tests for interface adherence, formulas, lag bonus, multi-scale roll-up, post-task logging, DCS modes, faction splits, modular off-switch, and provider swapping.
  - Integration tests for FastAPI endpoints and 503 off-switch response.
