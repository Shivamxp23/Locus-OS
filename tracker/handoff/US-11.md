## Plan (written before coding)
- Implement unified installer in `locus_cli/install.py`:
  - Validate prerequisites: Python 3.10+, Node 18+, Git, Docker (if mode requires it).
  - Support non-interactive mode via `--yes --answers <file.json>` and custom `--target-dir`.
  - Create target environment (`~/.locus/`) with subdirectories (`jobs/`, `logs/`, `data/`, `vault/`).

  - Generate initial `config.yaml` using defaults and answer parameters idempotently without overwriting existing configs.
  - Generate template `.env` if absent.
- Implement thin launchers at repository root:
  - `install.ps1`: checks Python 3.10+ and invokes `locus_cli.install`.
  - `install.sh`: checks Python 3.10+ and invokes `locus_cli.install`.
  - `install.bat`, `locus.bat`, `locus.cmd`: CMD entrypoints.
- Adopt top-level launcher files into `guard.toml` via `check.py --adopt-top-level`.
- Tests:
  - Add `tests/unit/test_install.py` testing launcher existence and scripts, prerequisite checks, non-interactive directory/config creation, idempotence, and CLI execution.
  - Create fixture `tests/fixtures/install_answers.json`.
- Tracker:
  - Update `tracker/features.yaml` for F-0082 to add `locus_cli/install.py` and `tests/unit/test_install.py`, reaching Level 3 (`UNIT_VERIFIED`).
