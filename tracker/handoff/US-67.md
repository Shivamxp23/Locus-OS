# US-67 handoff - Gemini Flash, 2027-06-16

## Plan (written before coding)
- Implement `AgentExperience`, `stable_experience_id`, `redact_text`, `ExperienceStore`, `AgentExperienceCaptureHook`, `render_experience_hits`, and `prepend_experience_block` in `sidecar/experience/procedural.py`.
- Ensure deterministic deduplication (`stable_experience_id`) by hashing normalized task summary, tool sequence, and outcome into a 24-char hex digest prefixed with `exp_`.
- Implement secret scrubbing (`redact_text`) for Bearer tokens, OpenAI-style `sk-` keys, and `password/token/secret/api_key` patterns before storage.
- Implement post-turn capture hook candidate extractors:
  1. Successful multi-tool sequence (>= 2 successful calls -> Success, confidence 0.72)
  2. Repeated failure (tool failed >= 2 times in turn -> Failure, confidence 0.68, error_class parsed)
  3. Partial success (failure followed by success -> Partial, confidence 0.62)
- Implement `BaseAgentExperienceProvider` and `DefaultAgentExperienceProvider` in `sidecar/providers/agent_experience.py` with modular off-switches:
  - `locus.agent_experience_tracking_procedural_memory.enabled`
  - `locus.experience.enabled`
- Re-export symbols in `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /experience/record`: post-turn capture hook for tool loops.
  - `POST /experience/query`: query scored procedural memories.
  - `POST /experience/render`: render and prepend Relevant Operating Experience block.
  - `GET /experience/list`: list stored experiences.
  - Off-switches returning HTTP 503 if disabled.
- Implement TypeScript contract `AgentExperienceClient` in `locus-extension/src/experience/client.ts`.
- Write unit tests in `tests/unit/test_agent_experience.py` and integration tests in `tests/integration/test_agent_experience_service.py`.
- Pi table:
  - Need: Procedural memory capturing agent experience trajectories and tool success/failure patterns across turns.
  - Pi mechanism: Pi has event streaming and tool dispatch loops in `packages/coding-agent/src/index.ts` but has zero procedural memory or experience tracking across sessions.
  - What Locus adds: Full procedural experience memory engine in `sidecar/experience/procedural.py`, `sidecar/providers/agent_experience.py`, and `locus-extension/src/experience/client.ts` with deterministic deduplication, token scrubbing, candidate extraction from post-turn tool loops, and prepending "Relevant Operating Experience" to context forge.
  - Why Pi's is not enough: Pi's session state is ephemeral; it forgets tool success/failure sequences between turns and does not learn from past tool loop recoveries or repeated failure patterns.
