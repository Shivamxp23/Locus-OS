# US-64 handoff - Gemini Flash, 2027-06-04

## Plan (written before coding)
- Implement `ACPEvent`, `ACPServer`, and `ACPClient` in `sidecar/acp_server.py` supporting standardized JSON-RPC 2.0 Agent Communication Protocol: capability negotiation handshake (`initialize`), agent task dispatch (`agent/execute`), streaming chunk events (`$/progress`, `$/streamText`, `$/toolCall`), and cancellation notification (`$/cancelRequest`).
- Implement `BaseACPClientProvider` and `DefaultACPClientProvider` in `sidecar/providers/acp_protocol.py` with modular off-switch (`locus.acp_protocol.enabled` and `locus.protocols.acp.enabled`).
- Re-export symbols in `sidecar/providers/__init__.py`.
- Implement TypeScript contract `ACPClient`, `ACPEvent`, and `ACPInitializeResult` in `locus-extension/src/protocols/acp/client.ts`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /protocols/acp/initialize`: JSON-RPC initialize handshake.
  - `POST /protocols/acp/execute`: dispatch task to target agent and return events.
  - `POST /protocols/acp/cancel`: cancel in-flight request by ID.
  - Off-switch returning HTTP 503 if ACP protocol is disabled.
- Write unit tests in `tests/unit/test_acp_protocol.py` and integration tests in `tests/integration/test_acp_protocol_service.py`.
- Pi table:
  - Need: Standardized JSON-RPC 2.0 Agent Communication Protocol (ACP) client and server transport to delegate tasks to and receive streaming updates from external IDE agents (e.g. Copilot, Claude Code).
  - Pi mechanism: Pi uses internal extension event dispatchers and session IPC (`agent-session.ts`), but lacks external JSON-RPC 2.0 ACP protocol negotiation, remote agent capability handshaking, and standardized streaming event multiplexing (`$/progress`, `$/streamText`, `$/toolCall`).
  - What Locus adds: Full JSON-RPC 2.0 ACP client and server transport in `sidecar/acp_server.py`, `sidecar/providers/acp_protocol.py`, and `locus-extension/src/protocols/acp/client.ts` with capability negotiation (`initialize`), task execution streaming (`agent/execute`), cancellation (`$/cancelRequest`), and FastAPI REST endpoints with 503 off-switch.
  - Why Pi's is not enough: Without ACP protocol support, Locus cannot communicate with or delegate tasks to external ACP-compliant IDE agent harnesses.
