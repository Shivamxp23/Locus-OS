# US-80 handoff - Gemini Flash, 2027-08-07

## Plan (written before coding)
- Implement Gateway Lifecycle Supervisor in `sidecar/gateway/lifecycle.py`:
  - `GatewayLifecycleManager`: orchestrates graceful restart, 30s connection draining loop, ingress adapter stop, session snapshotting, forensics telemetry, and database pool cleanup.
  - `BaseChannelAdapter` and `MockChannelAdapter`: abstract interface and deterministic mock for channel ingress management.
  - `SessionSnapshot`: in-memory session representation serialized to `~/.locus/sessions/recovery/{id}.json` and loaded on startup.
  - `ForensicRecord`: telemetry recorder saving shutdown reason, active sessions count, pending events, and server uptime.
- Implement `BaseGracefulRestartProvider` and `DefaultGracefulRestartProvider` in `sidecar/providers/graceful_restart.py` with modular off-switches:
  - `locus.graceful_restart.enabled`
  - `locus.gateway.graceful_restart.enabled`
- Re-export symbols in `sidecar/gateway/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /gateway/restart/initiate`: trigger graceful shutdown and connection drain sequence.
  - `POST /gateway/restart/drain`: drain active in-flight requests.
  - `POST /gateway/restart/snapshot`: serialize active sessions to recovery directory.
  - `GET /gateway/restart/recovery`: list recovered sessions from disk.
  - `GET /gateway/restart/status`: retrieve diagnostic lifecycle status.
  - Returns HTTP 503 when disabled.
- Implement TypeScript client contract in `locus-extension/src/gateway/lifecycle.ts`.
- Write unit tests in `tests/unit/test_graceful_restart.py` and integration tests in `tests/integration/test_graceful_restart_service.py`.
- Pi table:
  - Need: Zero-downtime gateway restart, connection draining, session crash recovery, and shutdown forensics.
  - Pi mechanism: Upstream Pi terminates synchronously without request draining or session state disk serialization.
  - What Locus adds: `GatewayLifecycleManager` in `sidecar/gateway/lifecycle.py`, 30s connection draining, recovery storage serialization, shutdown forensics telemetry, FastAPI endpoints, and TypeScript client contract with 503 off-switches.
  - Why Pi's is not enough: Upstream Pi drops active connections and in-flight messages upon restart.
