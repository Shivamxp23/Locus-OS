# US-46 handoff - Gemini 3.8 Flash, 2026-10-20

## Plan (written before coding)
- Implement `BaseMemoryProvider`, `EntityType` (POLE+O: Person, Object, Location, Event, Organization), `POLEEntity`, `Relationship`, `MemoryEntry`, `GraphQueryResult`, and `MemoryConfig` in `sidecar/providers/memory.py`.
- Re-export Graph-Native Memory provider contracts and types in `sidecar/providers/__init__.py`.
- Implement `Neo4jMemoryProvider` in `sidecar/neo4j_memory.py`:
  - Enforces POLE+O taxonomy on entity extraction and graph storage.
  - Automatically extracts POLE+O entities from ingested conversation turns and merges them into the graph.
  - Supports explicit relationship addition and multi-hop graph traversal.
  - Supports recording reasoning steps with explicit `:TOUCHED` audit edges to the entities involved.
  - `get_context`: Formats graph pathways into `src -[REL (w)]-> dst` format clamped to a configurable token budget (Context Forge Layer 4, 150t).
  - Health check reporting entity counts, relationship counts, reasoning traces, and POLE schema taxonomy.
  - Swappability via `BaseMemoryProvider` contract.
- Implement TypeScript client `Neo4jMemoryClient` in `locus-extension/src/neo4j-memory.ts` and re-export in `locus-extension/src/index.ts`.
- Register routes in `sidecar/service.py`:
  - `/memory/store`, `/memory/query`, `/memory/context`, `/memory/config`, `/memory/entity`, `/memory/entity/{entity_id}`, `/memory/reasoning`.
  - Off-switch returning 503 if `locus.memory.enabled` is False.
- Unit tests in `tests/unit/test_neo4j_memory.py` and integration tests in `tests/integration/test_neo4j_memory_service.py`.
- Pi table:
  - Need: Persistent graph-native knowledge memory tracking relationships between entities, session conversations, and tool reasoning traces.
  - Pi mechanism: Pi has no graph database or entity taxonomy; only flat in-memory conversation message history and basic text search.
  - What Locus adds: Graph-native memory with the POLE+O taxonomy (Person, Object, Location, Event, Organization) and `:TOUCHED` audit edges over Neo4j, exposing formatted graph pathways to Context Forge Layer 4.
  - Why Pi's is not enough: Flat message history cannot perform multi-hop relational queries, lacks auditability for which entities a reasoning step touched, and cannot bridge structured personal context into the prompt.
