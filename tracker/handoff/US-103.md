## Config keys
- `locus.auxiliary_llm_client.enabled`: Master toggle for Auxiliary LLM Client provider (default true, returns HTTP 503 when off).
- `locus.auxiliary_client.enabled`: Subsystem toggle for auxiliary client delegation (when false, falls back to main model).
- `auxiliary_model`: Custom auxiliary model override.
- `auxiliary_api_key`: Custom auxiliary API key.
- `deepseek_api_key`: API key for default DeepSeek V4 Flash client.
- `main_model`: Main model name for fallback execution.
