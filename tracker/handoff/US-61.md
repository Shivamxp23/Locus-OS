- Write unit tests in `tests/unit/test_tui_dashboard.py` and integration tests in `tests/integration/test_tui_dashboard_service.py`.
- Pi table:
  - Need: Terminal user interface providing real-time Life OS status (DCS, mode, faction), graph memory count, and sidecar probe health.
  - Pi mechanism: Pi provides `@earendil-works/pi-tui` pure-terminal UI engine and footer hooks (`ctx.ui.setFooter`, `ctx.ui.custom`), but lacks Locus Life OS DCS, Neo4j memory metrics, and sidecar health telemetry.
  - What Locus adds: Full 3-column dashboard renderer in Python sidecar with REST state/format endpoints, curses terminal UI fallback, and TypeScript extensions wiring into Pi's footer and modal overlays.
  - Why Pi's is not enough: Pi's base TUI only knows Pi session state and has no awareness of the self-hosted Locus cognitive architecture (DCS score, active faction, CouchDB sync, Neo4j graph nodes).
