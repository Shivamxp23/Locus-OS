## Discard table
- Instantaneous direct coordinate jumps discarded in favor of quadratic Bezier curve trajectory interpolation to provide human-like cursor interaction.

## Security
- Hard coordinate bounding-box safety gate (`BoundingBox`) verifies all pointer targets before event generation; attempts to click outside permitted boundaries raise `SecurityException` and return HTTP 403.
- Modular off-switches (`locus.vnc.enabled`, `locus.tools.vnc.enabled`) immediately cut off remote control with HTTP 503.
