# US-106 Handoff: Connectivity Check (F-0068)

## 1. Story

US-106 — Implement Connectivity Check (F-0068, §29.5). 2 story points.

## 2. What Was Built

- **`sidecar/diagnostics/connectivity.py`**: `ConnectivityChecker` class performing HTTP HEAD probes against configurable endpoints (`httpbin.org`, `1.1.1.1`) with TTL-based caching, service health checks via GET, and gate evaluation helpers for inner loop, model routing, vault sync, and web search.
- **`sidecar/providers/connectivity.py`**: `BaseConnectivityProvider` abstract contract and `DefaultConnectivityProvider` implementation wrapping `ConnectivityChecker` with modular off-switch (`locus.connectivity_check.enabled`), returning HTTP 503 when disabled.
- **`sidecar/service.py`**: Four FastAPI routes mounted: `GET|POST /connectivity/check`, `POST /connectivity/services`, `GET /connectivity/gates`, `GET /connectivity/status`. All enforce 503 off-switch.
- **`locus-extension/src/connectivity.ts`**: TypeScript `ConnectivityClient` class wrapping all four endpoints with typed interfaces (`ConnectivityStatus`, `ServiceCheckResult`, `ConnectivityGates`). Includes standalone gate helper functions (`shouldSkipInnerLoopWeb`, `shouldForceLocalModel`, `shouldSkipVaultSync`, `shouldSkipWebSearch`).
- **`locus-extension/src/index.ts`** and **`locus-extension/src/diagnostics/index.ts`**: Re-export connectivity module.
