## Pi Table
| need | Pi mechanism | what Locus adds | why Pi is not enough |
|---|---|---|---|
| Turn-by-turn trajectory recording & batch evaluation | Ephemeral in-memory turn array and unredacted raw session logs | `BaseTrajectoryRecorder`, `TrajectoryRecorder` with automated regex/env secret redaction, disk persistence (`.json`/`.json.gz`), batch evaluation metric aggregation, and sidecar HTTP endpoints with modular 503 off-switch | Upstream Pi does not redact API keys, DB passwords, or auth tokens from turn history, lacks structured multi-session metric aggregation (token distributions, tool call frequencies, error rates), and cannot be conditionally toggled via Locus config. |

## Plan (written before coding)
- Implement `sidecar/providers/trajectory.py`:
  - `BaseTrajectoryRecorder` abstract interface declaring `start_session()`, `record_turn()`, `flush_session()`, `get_trajectory()`, and `batch_evaluate()`.
  - Data transfer types: `TurnRecord`, `TrajectorySession`.
- Implement `sidecar/learning/trajectory.py`:
  - `TrajectoryRecorder` implementing `BaseTrajectoryRecorder`.
  - Automatic secret redaction: scans content, tool call arguments, and metadata for OpenAI `sk-...`, GitHub `ghp_...`, Bearer tokens, and secrets loaded from `LOCUS_HOME/.env` or environment, replacing with `[REDACTED]`.
  - Session lifecycle and persistence: records turns and flushes session trajectory to `LOCUS_HOME/trajectories/{session_id}.json` (with gzip compression support if enabled).
  - Batch evaluation: aggregates total sessions, turn counts, prompt/completion tokens, tool frequencies, role distributions, and error rates.
  - Modular off-switch: respects `locus.learning.trajectory.enabled`.
- Implement `locus-extension/src/trajectory.ts` & export in `locus-extension/src/index.ts`:
  - TypeScript types and turn formatting helpers for Pi agent extension turns.
- Update `sidecar/service.py`:
  - Endpoints `/trajectories/record`, `/trajectories/sessions/{session_id}/flush`, `/trajectories/sessions/{session_id}`, and `/trajectories/evaluate`.
  - Modular off-switch returning 503 `{"disabled": "locus.learning.trajectory.enabled"}` when disabled.
- Tests in `tests/unit/test_trajectory.py` and `tests/integration/test_trajectory_service.py`:
  - Unit tests for interface adherence, turn recording, secret redaction, batch evaluation, off-switch, compression, and modular swap.
  - Integration tests for FastAPI HTTP routes and off-switch 503 response.

## Config keys and defaults added
- `locus.learning.trajectory.enabled`: boolean flag toggling trajectory recording and service endpoints (default `true`).
- `locus.learning.trajectory.dir`: path to directory where trajectory JSON files are saved (default `LOCUS_HOME/trajectories`).
- `locus.learning.trajectory.compress`: boolean flag to enable gzip compression (`.json.gz`) (default `false`).
