# US-65 handoff - Gemini Flash, 2027-06-08

## Plan (written before coding)
- Implement `PluginLLMBridge`, `AuxiliaryClient`, `DefaultAuxiliaryClient`, `AuxiliaryClientPool`, `QuotaExceededError`, and `AuxiliaryTimeoutError` in `sidecar/plugins/llm_bridge.py` supporting sandboxed secondary LLM execution for extensions/plugins with isolated execution context (protecting main model prompt cache), per-plugin daily token quota enforcement, persistent usage tracking in `~/.locus/usage/plugins.json`, and 15s fail-fast timeout.
- Implement `BasePluginLLMProvider` and `DefaultPluginLLMProvider` in `sidecar/providers/plugin_llm.py` with modular off-switches (`locus.plugin_llm.enabled` and `locus.plugins.auxiliary_llm.enabled`).
- Re-export symbols in `sidecar/providers/__init__.py`.
- Implement TypeScript contract `PluginLLMBridgeClient`, `PluginLLMMessage`, `PluginLLMQuotaInfo`, and request/response interfaces in `locus-extension/src/plugins/llm-bridge.ts`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /plugins/llm/generate`: sandboxed plugin LLM call with daily quota enforcement.
  - `GET /plugins/llm/quota`: return daily quota & remaining tokens for plugin.
  - `POST /plugins/llm/reset`: reset daily token counter.
  - `GET /plugins/llm/usage`: aggregate token usage records across all plugins.
  - Off-switch returning HTTP 503 if Plugin LLM is disabled.
- Write unit tests in `tests/unit/test_plugin_llm.py` and integration tests in `tests/integration/test_plugin_llm_service.py`.
- Pi table:
  - Need: Sandboxed secondary LLM execution bridge for extensions and background tools (Excalidraw, note parsers, link dump loggers) protecting the main conversation prompt cache from pollution, enforcing daily token budgets, and failing fast on timeouts.
  - Pi mechanism: Upstream Pi provides a single primary model execution loop with shared context (`packages/coding-agent/src/index.ts`).
  - What Locus adds: Full sandboxed auxiliary execution bridge in `sidecar/plugins/llm_bridge.py`, `sidecar/providers/plugin_llm.py`, and `locus-extension/src/plugins/llm-bridge.ts` with quota enforcement, persistent usage tracking in `~/.locus/usage/plugins.json`, 15.0s timeout containment, and REST endpoints with 503 off-switch.
  - Why Pi's is not enough: Pi's architecture cannot run background plugin transformations without mixing messages into the primary conversation session or running uncontrolled token usage.
