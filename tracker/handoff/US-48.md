# US-48 handoff - Gemini 3.8 Flash, 2026-10-20

## Plan (written before coding)
- Implement `SyncPipelineKind`, `SyncOutcome`, `SourceScope`, `MemorySyncConfig`, `BaseSyncPipeline`, and `BaseMemorySyncProvider` in `sidecar/providers/memory_sync.py`.
- Re-export Memory Sync provider contracts and types in `sidecar/providers/__init__.py`.
- Implement `MemorySyncManager`, `WorkspaceSyncPipeline`, `DirectAPISyncPipeline`, and `McpSyncPipeline` in `sidecar/memory_sync.py`:
  - `WorkspaceSyncPipeline`: Local files, watches Obsidian markdown files, detects new/changed files using MD5, normalizes into chunks.
  - `DirectAPISyncPipeline` (Composio kind): Ingests external API sources (GitHub, Gmail, Slack) with pagination cursors and rate-limit backoff.
  - `McpSyncPipeline`: Ingests from connected MCP servers using standard tool/resource calls.
  - Self-healing raw-archive coverage: `check_and_rebuild_tree(source, on_disk_files)` computes set difference `uncovered = set(on_disk_files) - set(ingested_ids)` and self-heals missed files.
  - Periodic scheduler loops (`tick_all` and `tick_pipeline`) with SQLite history tracking (`mem_sync_pipelines`, `mem_sync_history`, `mem_tree_ingested_sources`).
  - Strict layer boundaries: all records canonicalize through the ingestion pipeline.
- Implement TypeScript client `MemorySyncClient` in `locus-extension/src/memory-sync.ts` and re-export in `locus-extension/src/index.ts`.
- Register routes in `sidecar/service.py`:
  - `GET /memory/sync/config`, `GET /memory/sync/pipelines`, `POST /memory/sync/tick/{pipeline_id}`, `POST /memory/sync/tick_all`, `POST /memory/sync/heal`.
  - Modular off-switch returning 503 if `locus.memory_sync_multi_source_ingestion_pipelines.enabled` (or `locus.memory.sync.enabled`) is False.
- Unit tests in `tests/unit/test_memory_sync.py` and integration tests in `tests/integration/test_memory_sync_service.py`.
- Pi table:
  - Need: Multi-source ingestion pipelines pulling from local workspace, remote APIs, and MCP servers into the memory store with automatic self-healing.
  - Pi mechanism: Pi has no background sync pipelines, no pagination cursors, and no self-healing raw-archive reconciliation.
  - What Locus adds: Unified `SyncPipeline` architecture across Composio, Workspace, and MCP sources with SQLite state tracking, rate limiting, and raw-archive set difference self-healing.
  - Why Pi's is not enough: Without automated multi-source ingestion pipelines, memories can only be added manually during active chat turns, causing data silos and unindexed vault/remote knowledge.
