## Plan (written before coding)
- Implement `AutonomyTier`, `ToolCategory`, `TierEvaluationDecision`, and `AutonomyTierManager` in `sidecar/security/autonomy_tiers.py`.
- `AUTONOMY TIERS`:
  - `READONLY`: read tools only, no writes, no terminal execution.
  - `SUPERVISED`: write and terminal tools require explicit user approval (10-min TTL).
  - `FULL`: all tools allowed (trusted mode).
- Tool categorization: maps built-in and custom tools into `read`, `write`, `terminal`, and `system` categories with heuristic regex classification and manual override registration.
- Implement `BaseAutonomyTiersProvider` and `DefaultAutonomyTiersProvider` in `sidecar/providers/autonomy_tiers.py` with modular off-switches:
  - `locus.autonomy_tiers.enabled`
  - `locus.security.autonomy_tiers.enabled`
- Re-export symbols in `sidecar/security/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `GET /security/autonomy/tier`: gets active autonomy tier.
  - `POST /security/autonomy/tier`: sets active tier.
  - `POST /security/autonomy/evaluate`: evaluates tool execution against active tier policies and user approval status.
  - `POST /security/autonomy/classify`: classifies tool names into operational categories.
  - `GET /security/autonomy/tiers`: lists tier metadata and capability matrix.
  - Off-switches returning HTTP 503 if disabled.
- Implement TypeScript contract `AutonomyTiersClient` in `locus-extension/src/security/autonomy-tiers.ts`, including `createBeforeToolCallHook` adapting to Pi's `beforeToolCall` agent loop hook.
- Write unit tests in `tests/unit/test_autonomy_tiers.py` and integration tests in `tests/integration/test_autonomy_tiers_service.py`.
- Pi table:
  - Need: Enforcing tiered operational constraints (READONLY, SUPERVISED, FULL) and approval gates on tool calls before execution.
  - Pi mechanism: Upstream Pi provides the raw hook interface `beforeToolCall` in `packages/agent/src/types.ts:326`.
  - What Locus adds: Full autonomy tier classification, rule evaluation engine, REST endpoints, and approval requirement policies in `sidecar/security/autonomy_tiers.py`, `sidecar/providers/autonomy_tiers.py`, and `locus-extension/src/security/autonomy-tiers.ts`.
  - Why Pi's is not enough: Pi's `beforeToolCall` is only an unopinionated callback hook signature; it contains no tier policies, no role-based execution constraints, no tool classification, and no approval gating.
