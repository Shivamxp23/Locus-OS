# US-49 handoff - Gemini 3.8 Flash, 2026-10-20

## Plan (written before coding)
- Implement `JobKind`, `JobStatus`, `JobRecord`, `MemoryQueueConfig`, and `BaseMemoryQueueProvider` in `sidecar/providers/memory_queue.py`.
- Re-export Memory Queue provider contracts and types in `sidecar/providers/__init__.py`.
- Implement `SqliteMemoryQueue` in `sidecar/memory_queue.py`:
  - Persistence in SQLite table `mem_tree_jobs` with partial unique index `(dedupe_key) WHERE status IN ('ready', 'running')`.
  - Duplicate suppression using `INSERT OR IGNORE RETURNING id` (at-most-one-active job suppression).
  - Atomic claim pattern: `UPDATE ... RETURNING` assigning unique `claim_token` without select races.
  - Settlement guards: `mark_done` and `mark_failed` enforce token matching; stale settlements are no-ops.
  - Stale lock recovery: `UPDATE mem_tree_jobs SET status='ready', claim_token=NULL WHERE status='running' AND claimed_at <= now - lock_duration`.
  - Scheduler helpers: `trigger_digest`, `backfill_missing_digests`, `flush_stale_daily`, and `daily_tick`.
  - Worker execution harness with 3-permit LLM semaphore and throttle gating.
- Implement TypeScript client `MemoryQueueClient` in `locus-extension/src/memory-queue.ts` and re-export in `locus-extension/src/index.ts`.
- Register routes in `sidecar/service.py`:
  - Static endpoints before parameterized path endpoints: `GET /memory/queue/config`, `GET /memory/queue/stats`, `GET /memory/queue/jobs`, `POST /memory/queue/enqueue`, `POST /memory/queue/claim`, `POST /memory/queue/settle`, `POST /memory/queue/recover_stale`, `POST /memory/queue/trigger_digest`, `POST /memory/queue/backfill_digests`, `POST /memory/queue/flush_stale`, `POST /memory/queue/daily_tick`.
  - Parameterized endpoint: `GET /memory/queue/jobs/{job_id}`.
  - Modular off-switch returning 503 if `locus.memory_queue_async_job_pipeline.enabled` is False, `locus.memory.queue.enabled` is False, or `locus.memory.queue.workers <= 0`.
- Unit tests in `tests/unit/test_memory_queue.py` and integration tests in `tests/integration/test_memory_queue_service.py`.
- Pi table:
  - Need: Async job execution pipeline to offload chunk extraction, multi-level summarization cascade, and daily digesting from the synchronous ingest hot path.
  - Pi mechanism: Pi performs all memory extractions synchronously or blocks during turn processing.
  - What Locus adds: SQLite job queue (`mem_tree_jobs`) with atomic claim tokens, duplicate suppression, rate-limiting LLM concurrency semaphores, and daily scheduler ticks.
  - Why Pi's is not enough: Synchronous ingestion causes high turn latency and risk of dropped messages during LLM summarization cascades.
