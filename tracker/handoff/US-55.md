## Discard table
- Discarded simple token truncation in favor of Hermes 7-step head/middle/tail preservation to ensure user instructions and recent dialog are never lost during compaction.
- Discarded inline synchronous LLM call inside `compress()` in favor of injectable summarizer callable to allow zero-network deterministic unit tests and pluggable model drivers.

## Security
- Compaction operations bound to loopback `127.0.0.1`.
- Thread-safe `CompactionLock` prevents race conditions or duplicate concurrent LLM compaction requests from exhausting compute.
- Summarizer input strictly retains message content without executing code or dynamic eval.
