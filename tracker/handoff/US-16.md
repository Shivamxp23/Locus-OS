## Security (anything found, even if outside this story)
- Security Rule S-2 strictly enforced:
  - `docker-compose.yml` binds `127.0.0.1:5984:5984`.
  - `local.ini` locks CORS origins strictly to Obsidian app origins (`app://obsidian.md`, `capacitor://localhost`, `http://localhost`).
  - `validate_transport_security` in `sidecar/vault/livesync_bridge.py` rejects unencrypted remote HTTP endpoints.
  - Secret credentials (`COUCHDB_USER`, `COUCHDB_PASSWORD`) are loaded via `sidecar.config.get_env` from environment or `~/.locus/.env`, never hardcoded or committed.
