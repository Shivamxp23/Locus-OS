## Plan (written before coding)
- Implement `sidecar/providers/vault_sync.py`:
  - `BaseVaultSyncProvider` abstract interface declaring `status()`, `push(path)`, `pull(path)`, and `resolve_conflicts(path, remote_content, base_content)`.
  - Data transfer types: `SyncState`, `SyncResult`.
- Implement `sidecar/vault/livesync_bridge.py`:
  - `CouchDBLiveSyncProvider` integrating with Obsidian LiveSync CouchDB protocol.
  - Reject default CouchDB credentials ("admin", "password", "couchdb") and require non-empty secret from `LOCUS_HOME/.env` via `config.get_env("COUCHDB_PASSWORD")`.
  - Enforce loopback binding: host must be `127.0.0.1`, `localhost`, `::1`, or valid HTTPS/VPN URL; forbid public `0.0.0.0`.
  - Deterministic conflict resolution: attempt clean diff3 3-way line merge; on collision, use deterministic tiebreaker `(mtime, sha256)` to pick canonical winner without conflict markers, and save losing revision into `<stem>.conflict.<timestamp>.<hash>.md`.
  - Chunk assembly and disassembly for LiveSync compatibility.
- Update `sidecar/service.py`:
  - Register `/vault/sync/status` and `/vault/sync/push` endpoints.
  - Implement modular off-switch: when `locus.vault.sync.enabled` is false, return 503 with `{"disabled": "locus.vault.sync.enabled"}` per SPEC §03 line 35.
- Update `locus-extension/src/tools/locus_vault.ts` & `locus-extension/src/index.ts`:
  - Provide `locus_vault_write` tool for Pi Agent, invoking local sidecar `/vault/sync/push` on write.
- Tests in `tests/unit/test_livesync.py` and `tests/integration/test_livesync_couchdb.py`:
  - Unit tests for interface adherence, loopback verification, default credential rejection, diff3 clean merge, deterministic conflict sidecar note generation, and modular off-switch.
  - Integration test for sidecar HTTP endpoints and off-switch 503.

## Config keys and defaults added
- `locus.vault.sync.enabled`: boolean flag toggling sync provider and HTTP endpoints (default `true`).
- `locus.vault.sync.provider`: sync provider name (default `couchdb_livesync`).

- `locus.vault.sync.couchdb_user`: CouchDB username (default `locus_sync`).
- `locus.vault.sync.couchdb_db`: CouchDB database name (default `locus_vault`).
