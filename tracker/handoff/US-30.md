## Plan (written before coding)
- Implement `BaseTitleGeneratorProvider`, `TitleGenerationRequest`, and `TitleGenerationResult` in `sidecar/providers/title_generator.py`.
- Re-export `BaseTitleGeneratorProvider`, `TitleGenerationRequest`, and `TitleGenerationResult` in `sidecar/providers/__init__.py`.
- Implement `TitleGeneratorProvider` in `sidecar/title_generator.py`:
  - Standardized 3-7 word prompt template (`TITLE_SYSTEM_PROMPT`).
  - 500-char input truncation for user message and assistant response snippets.
  - Comprehensive artifact cleanup pipeline: strip outer quotes, strip "Title:" / "title:" prefix, strip trailing punctuation, clamp to 80 chars max (`title[:77] + "..."`).
  - Synchronous and asynchronous execution (`generate_title_async`) with non-blocking daemon thread and callback execution.
  - Fallback timestamp-based session title generator ("Session YYYY-MM-DD HH:MM").
  - Provider registration with `get_registry().register("title_generator", "default", TitleGeneratorProvider)`.
- Implement TypeScript component in `locus-extension/src/sessions/title-gen.ts` and `locus-extension/src/title-generator.ts`, and re-export in `locus-extension/src/index.ts`.
- Register routes `/title/generate`, `/title/clean`, and `/title/prompt` in `sidecar/service.py` with 503 off-switch on `locus.title_generation.enabled` and `locus.sessions.auto_title.enabled`.
- Unit tests in `tests/unit/test_title_generator.py` and integration tests in `tests/integration/test_title_generator_service.py`.
- Pi table:
  - Need: Asynchronous, non-blocking generation of short, descriptive 3-7 word titles for new sessions from the first turn.
  - Pi mechanism: Pi has session persistence where session titles can be set via `session.setTitle()` or session metadata, but Pi does not have an automatic background title generation pipeline.
  - What Locus adds: Standardized 3-7 word prompt template, 500-char input truncation, artifact cleaning pipeline (strips quotes, "Title:" prefix, trailing punctuation, 80-char max truncation), asynchronous background dispatch, fallback generation, and modular off-switch (`locus.title_generation.enabled` / `locus.sessions.auto_title.enabled`).
  - Why Pi's is not enough: Pi only creates default session IDs or timestamps, without automated background LLM title generation, artifact cleaning, or configurable off-switches.
