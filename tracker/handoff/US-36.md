# US-36 handoff - Gemini 3.8 Flash, 2026-10-20

## Plan (written before coding)
- Implement `BaseStreamingSSEProvider`, `SSEEvent`, and `StreamOptions` in `sidecar/providers/streaming_sse.py`.
- Re-export streaming SSE contracts in `sidecar/providers/__init__.py`.
- Implement `StreamingSSEProvider` in `sidecar/streaming_sse.py`:
  - `format_event`: serializes payload into SSE wire format with `event:`, `id:`, `retry:`, and multiline `data:` fields.
  - `parse_event`: parses raw wire chunks into `SSEEvent` objects, correctly ignoring comment lines (`:`).
  - `format_ping`: generates heartbeat ping event frame (`event: ping`).
  - `stream_tokens`: async generator streaming tokens as SSE frames with terminal `event: done` frame.
  - `stream_text_chunks`: chunks raw text into configured chunk sizes and yields SSE frames.
  - Register provider in registry under `("streaming_sse", "default", StreamingSSEProvider)`.
  - Add modular off-switch logic checking `locus.streaming_sse.enabled`.
- Implement TypeScript extension client in `locus-extension/src/streaming-sse.ts` with `SSEFrameDecoder` and `StreamingSSEConsumer`, and re-export in `locus-extension/src/index.ts`.
- Register routes `/stream/events` and `/stream/config` in `sidecar/service.py` with 503 off-switch.
- Unit tests in `tests/unit/test_streaming_sse.py` and integration tests in `tests/integration/test_streaming_sse_service.py`.
- Pi table:
  - Need: Real-time Server-Sent Events (SSE) streaming format and transport for LLM turn tokens, tools progress, and heartbeats.
  - Pi mechanism: Pi has built-in streaming in `packages/agent/src/agent-loop.ts` and `stream.ts` via event callbacks, but does not provide a standalone FastAPI SSE proxy bridge, wire-format parser, or modular off-switch for web clients.
  - What Locus adds: Standardized SSE wire encoder/decoder, keep-alive heartbeat framing, FastAPI `/stream/events` endpoint with modular 503 off-switch on `locus.streaming_sse.enabled`, and swappable streaming provider contract.
  - Why Pi's is not enough: External clients, web interfaces, and sidecar consumers require HTTP SSE transport rather than direct TypeScript in-process event listener callbacks.
