## Plan (written before coding)
- Implement `BaseStateEngineProvider`, `CheckInRecord`, `CurrentState`, and `OperatingMode` in `sidecar/providers/state_engine.py`.
- Re-export state engine contracts in `sidecar/providers/__init__.py`.
- Implement `StateEngineProvider` in `sidecar/state_engine.py`:
  - STEP 1: Write trigger reception / thread-safe state storage with `threading.RLock()`.
  - STEP 2: Last check-in read with staleness penalties:
    - If no check-in today: all scores multiplied by 0.9 and `CHECKIN_DUE_TODAY` alert queued.
    - If no check-in in 3+ days: default to baseline (5, 5, 5, 7) and queue `STALE_CHECKIN` alert.
  - STEP 3: Canonical DCS calculation: `DCS = ((E + M + S) / 3) * (1 - ST / 20)` with `ST = input_stress * 2`.
  - STEP 4: Operating Mode determination:
    - DCS 0.0 - 2.0 -> `SURVIVAL`
    - DCS 2.1 - 4.0 -> `RECOVERY`
    - DCS 4.1 - 6.0 -> `NORMAL`
    - DCS 6.1 - 8.0 -> `DEEP_WORK`
    - DCS 8.1 - 10.0 -> `PEAK`
  - STEP 5: State snapshot caching (`CURRENT_STATE`): `{ dcs, operating_mode, energy, mood, stress, sleep, active_alerts[], inferred_cause_chain }`.
  - Provider registration with `get_registry().register("state_engine", "default", StateEngineProvider)`.
- Implement TypeScript client component in `locus-extension/src/state-engine.ts` and re-export in `locus-extension/src/index.ts`.
- Register routes `/state/current`, `/state/calculate`, `/state/reset` in `sidecar/service.py` with 503 off-switch on `locus.state_engine.enabled`.
- Unit tests in `tests/unit/test_state_engine.py` and integration tests in `tests/integration/test_state_engine_service.py`.
- Pi table:
  - Need: Runtime cognitive state injection (Stage 3 in reactive loop) computing Daily Capacity Score (DCS) and operating mode constraints to govern context building and task difficulty.
  - Pi mechanism: Pi has no concept of biological energy, circadian rhythms, cognitive load scoring, or operating modes; it operates statelessly on raw turns.
  - What Locus adds: Canonical DCS formula, 5-tier operating modes (`SURVIVAL` to `PEAK`), staleness decay penalties, automated alerts (`STALE_CHECKIN`, `CHECKIN_DUE_TODAY`), and modular off-switch (`locus.state_engine.enabled`).
  - Why Pi's is not enough: Pi treats all turns identically without knowing whether the user has cognitive headroom for deep work or is in low-energy survival mode.
