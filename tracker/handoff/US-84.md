## Security
- Docker port bindings are strictly audited: any container exposing ports to `0.0.0.0` or missing `127.0.0.1` binding triggers a security violation per errata D-13.
- Systemd units configure `NoNewPrivileges=true`, `PrivateTmp=true`, and `ProtectSystem=full`.
- Modular off-switches immediately disable deployment operations with HTTP 503.
