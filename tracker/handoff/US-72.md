# US-72 handoff - Gemini Flash, 2027-07-06

## Plan (written before coding)
- Implement `SENSITIVE_HOME_DIRS`, `SENSITIVE_HOME_FILES`, `DEFAULT_BLOCKED_PATTERNS`, `ShellInspectionDecision`, and `ShellPolicyEngine` in `sidecar/security/shell_policy.py`.
- `SENSITIVE_HOME_DIRS`: Blocks reading and command execution targeting sensitive home directories (`.ssh`, `.aws`, `.gnupg`, `.kube`, `.docker`, `.azure`, `.config/gh`).
- `SENSITIVE_HOME_FILES`: Protects critical credentials and shell rc files (`.bashrc`, `.zshrc`, `.profile`, `.netrc`, `.pgpass`, `.npmrc`, `.pypirc`).
- `BLOCKED_SHELL_PATTERNS`: Implements regex analysis catching destructive wipes (`rm -rf /`, `rm -rf ~`, `rm -rf $HOME`), fork bombs (`:(){ :|:& };:`), global unsafe permissions (`chmod -R 777`), unsigned remote pipe-to-shell (`curl | sh`, `wget | sh`), dangerous privilege escalations (`sudo rm`, `sudo chmod`), and raw disk formats.
- Implement `BaseShellBlocklistProvider` and `DefaultShellBlocklistProvider` in `sidecar/providers/shell_blocklist.py` with modular off-switches:
  - `locus.shell_blocklist.enabled`
  - `locus.security.shell_blocklist.enabled`
- Re-export symbols in `sidecar/security/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /security/shell/check`: inspects shell commands against dangerous and sensitive patterns.
  - `POST /security/shell/check_path`: validates paths against sensitive user directories and boundary policies.
  - `GET /security/shell/patterns`: lists active blocklist rules.
  - Off-switches returning HTTP 503 if disabled.
- Implement TypeScript contract `ShellPolicyClient` in `locus-extension/src/security/shell-policy.ts`, with `createBeforeToolCallHook` pre-screening command arguments in terminal tool calls.
- Write unit tests in `tests/unit/test_shell_blocklist.py` and integration tests in `tests/integration/test_shell_blocklist_service.py`.
- Pi table:
  - Need: Shell command policy inspection and blocklist enforcement before execution, preventing destructive commands and unauthorized access to sensitive home files.
  - Pi mechanism: Upstream Pi provides the raw hook interface `beforeToolCall` in `packages/agent/src/types.ts:326`.
  - What Locus adds: Full `ShellPolicyEngine`, `DefaultShellBlocklistProvider`, FastAPI endpoints, and TypeScript `ShellPolicyClient` with regex command scanning and 503 off-switches.
  - Why Pi's is not enough: Pi does not inspect command payloads or block destructive patterns prior to execution.
