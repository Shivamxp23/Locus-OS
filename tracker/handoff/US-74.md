# US-74 handoff - Gemini Flash, 2027-07-14

## Plan (written before coding)
- Implement `SUPPORTED_TAGS`, `ScrubState`, and `StreamingThinkScrubber` state machine in `sidecar/security/think_scrubber.py`.
- `StreamingThinkScrubber`:
  - Recognizes tags `think`, `thinking`, `reasoning`, `thought`, `REASONING_SCRATCHPAD`.
  - States: `NORMAL`, `PENDING_TAG`, `INSIDE_BLOCK`.
  - `feed(delta_text)`: handles streamed chunk deltas across boundary splits, holding back potential tags until matched or refuted.
  - `_is_block_boundary()`: ensures block tags are only suppressed at start of stream, after newlines, or whitespace-only lines, preserving inline prose mentions like "write <think> tags".
  - `flush()`: emits held-back text if stream completes while still resolving a potential tag.
  - `reset()`: resets state machine for next turn.
  - `process_complete(text)`: batch helper for complete text payloads.
- Implement `BaseThinkScrubberProvider` and `DefaultThinkScrubberProvider` in `sidecar/providers/think_scrubber.py` with modular off-switches:
  - `locus.think_token_scrubbing.enabled`
  - `locus.security.think_scrubbing.enabled`
- Re-export symbols in `sidecar/security/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /security/think_scrubber/feed`: feeds stream delta chunks.
  - `POST /security/think_scrubber/flush`: flushes held-back buffer at stream termination.
  - `POST /security/think_scrubber/scrub_complete`: batch scrubs complete payloads.
  - `POST /security/think_scrubber/reset`: resets turn state.
  - `GET /security/think_scrubber/tags`: lists supported tags.
  - Returns HTTP 503 when disabled.
- Implement TypeScript client and streaming state machine in `locus-extension/src/security/think-scrubber.ts`.
- Write unit tests in `tests/unit/test_think_scrubber.py` and integration tests in `tests/integration/test_think_scrubber_service.py`.
- Pi table:
  - Need: Streaming thought / reasoning token scrubbing preventing internal chain-of-thought blocks from leaking to the end user.
  - Pi mechanism: Upstream Pi provides the raw hook interface `stream_delta_callback` in `packages/agent/src/types.ts`.
  - What Locus adds: Full streaming state machine `StreamingThinkScrubber`, `DefaultThinkScrubberProvider`, FastAPI endpoints, and TypeScript contract with 503 off-switches.
  - Why Pi's is not enough: Upstream Pi passes model output deltas directly through to listeners without detecting reasoning tags or buffering delta splits.
