- Implement `BaseQueryRouterProvider`, `IntentType`, `TemporalScope`, `RoutingManifest`, and `ALL_RETRIEVAL_SOURCES` in `sidecar/providers/query_router.py`.
- Re-export query router contracts in `sidecar/providers/__init__.py`.
- Implement `QueryRouterProvider` in `sidecar/router/classifier.py`:
  - STEP 1: Accepts input query string.
  - STEP 2: Compact prompt builder `<200 tokens` (`build_classifier_prompt`) defining all 8 categories with JSON schema output.
  - STEP 3: Classification call returning `{ intent_type, sources_required, temporal_scope, deep_reasoning, confidence }`.
  - STEP 4: Anti-hallucination confidence gate: `IF confidence < 0.7: sources_required = ["pg", "neo4j", "pgvector", "pageindex"]`.
  - STEP 5: Temporal scope resolution: `TODAY` (00:00 to 23:59 IST), `WEEK` (last 7 days), `MONTH` (last 30 days), `ALLTIME` (None to now) yielding `start_ts` and `end_ts` Unix timestamps.
  - STEP 6: Return structured `RoutingManifest` object.
  - Provider registration with `get_registry().register("query_router", "default", QueryRouterProvider)` and alias `"intent_classifier"`.
- Implement TypeScript client component in `locus-extension/src/intent-classifier.ts` and re-export in `locus-extension/src/index.ts`.
- Register route `POST /router/classify` in `sidecar/service.py` with 503 off-switch on `locus.query_router.enabled`.
- Unit tests in `tests/unit/test_query_router.py` and integration tests in `tests/integration/test_query_router_service.py`.
- Pi table:
  - Need: Pre-retrieval query routing and intent classification (Stage 2) in the 12-stage cognitive reactive loop, determining which retrieval sources (pg, neo4j, pgvector, pageindex) to execute in parallel at Stage 4.
  - Pi mechanism: Pi operates as an interactive agent that directly feeds raw user input into an LLM tool-calling loop without multi-database intent routing or multi-hop retrieval gating.
  - What Locus adds: 8-category intent classification, structured `RoutingManifest`, anti-hallucination confidence gate (<0.7 forces querying all 4 data stores), temporal window parsing (`start_ts`, `end_ts`), and modular off-switch (`locus.query_router.enabled`).
  - Why Pi's is not enough: Pi has no concept of database routing, temporal bounds, or anti-hallucination confidence gates across heterogenous cognitive data layers.
