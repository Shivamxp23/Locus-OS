## CouchDB Existing Data Directory Admin Password Migration
CouchDB applies `COUCHDB_PASSWORD` only upon initial database initialization when creating the admin user; if a database data directory (`data/couchdb/`) has already been initialized, CouchDB ignores changes to the `COUCHDB_PASSWORD` environment variable.

To rotate or apply a new admin password to an already-initialized data directory:
1. Issue a configuration update request to the CouchDB HTTP API:
   ```bash
   curl.exe -X PUT http://127.0.0.1:5984/_node/nonode@nohost/_config/admins/admin \
     -u "admin:<old_password>" \
     -d "\"<new_password>\""
   ```
2. Verify that the previous login is rejected immediately:
   ```bash
   curl.exe -s -o NUL -w "%{http_code}" -u admin:<old_password> http://127.0.0.1:5984/
   # Expected output: 401
   ```
3. Verify that the new credentials succeed:
   ```bash
   curl.exe -s -o NUL -w "%{http_code}" -u admin:<new_password> http://127.0.0.1:5984/
   # Expected output: 200
   ```
