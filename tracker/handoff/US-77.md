# US-77 handoff - Gemini Flash, 2027-07-26

## Plan (written before coding)
- Implement 8 Web Search Providers and Mock provider in `sidecar/search/providers.py`:
  - `BaseSearchProvider`: abstract interface with `search(query, max_results)`.
  - `OpenAISearchProvider`: OpenAI web search provider.
  - `BraveSearchProvider`: Brave Search API provider.
  - `ParallelSearchProvider`: Parallel indexed search provider.
  - `TavilySearchProvider`: Tavily AI search provider.
  - `ExaSearchProvider`: Exa neural embeddings search provider.
  - `PerplexitySearchProvider`: Perplexity AI citations search provider.
  - `GeminiSearchProvider`: Google Search grounding provider.
  - `FullContentFetchProvider`: full webpage retrieval, parsing, and markdown extraction.
  - `MockSearchProvider`: deterministic search fixture provider for offline environments and unit testing.
- Implement `WebSearchManager` in `sidecar/search/manager.py`:
  - Registers all 8 providers + mock fallback.
  - Automatically selects active provider based on availability or falls back to mock.
  - Supports provider routing, runtime provider swapping (`set_provider`), and URL content fetching.
- Implement `BaseWebSearchProvider` and `DefaultWebSearchProvider` in `sidecar/providers/web_search.py` with modular off-switches:
  - `locus.web_search_8_providers.enabled`
  - `locus.web_search.enabled`
- Re-export symbols in `sidecar/search/__init__.py` and `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /search/query`: query web across active or requested provider.
  - `POST /search/fetch`: fetch full content of a webpage / URL.
  - `GET /search/providers`: list registered and available providers.
  - Returns HTTP 503 when disabled.
- Implement TypeScript client contract in `locus-extension/src/search/web-search.ts`.
- Write unit tests in `tests/unit/test_web_search.py` and integration tests in `tests/integration/test_web_search_service.py`.
- Pi table:
  - Need: Web search across multi-provider backends (OpenAI, Brave, Parallel, Tavily, Exa, Perplexity, Gemini, Full Content Fetch) with modular fallback.
  - Pi mechanism: Upstream Pi provides `pi/web_search` tool definitions.
  - What Locus adds: Multi-provider backend engine (`sidecar/search/`), `WebSearchManager`, modular provider interface (`DefaultWebSearchProvider`), FastAPI endpoints, and TypeScript contract with 503 off-switches.
  - Why Pi's is not enough: Upstream Pi tool requires a live single configured key and lacks headless REST API endpoints, full-content fetch provider, and multi-provider runtime swapping.
