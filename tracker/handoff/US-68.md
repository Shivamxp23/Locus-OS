# US-68 handoff - Gemini Flash, 2027-06-20

## Plan (written before coding)
- Implement `NormalizedPrompt`, `PromptEnforcementDecision`, `normalize_prompt`, `enforce_prompt_input`, and `scan_tool_definition` in `sidecar/security/injection_filter.py`.
- Step 1 Normalization: single-character pass performing lowercasing, leet-speak folding (`0→o, 1→i, 3→e, 4→a, 5→s, 7→t, 8→b, 6→g, @→a`), Cyrillic homoglyph folding (UAX#39 confusables), zero-width / formatting character stripping + flag detection (`had_zwsp`), fullwidth ASCII folding, and whitespace collapsing/stripping.
- Step 2 Detection Rules: implement exact scored DFA rules (`override.ignore_previous` 0.44, `override.role_hijack` 0.30, `exfiltrate.system_prompt` 0.42, `exfiltrate.secrets` 0.18, `exfiltrate.credentials_with_intent` 0.46 excluding high-false-positive verbs, `tool.abuse` 0.30).
- Step 3 & 4 Heuristics: inline heuristics (obfuscated instruction +0.56, exfiltration intent +0.24) and heuristic classifier combinations.
- Step 5 & 6 Verdict & Audit: fixed thresholds (Review >= 0.55, Block >= 0.70) and PII-safe audit logging using SHA-256 hash (never persisting or logging raw prompt text).
- Step 7 Tool Definition Scanning: `scan_tool_definition` rejecting tools with prompt-injected descriptions/titles.
- Implement `BaseInjectionFilterProvider` and `DefaultInjectionFilterProvider` in `sidecar/providers/injection_filter.py` with modular off-switches:
  - `locus.injection_filter.enabled`
  - `locus.security.prompt_injection.enabled`
- Re-export symbols in `sidecar/providers/__init__.py`.
- Mount FastAPI endpoints in `sidecar/service.py`:
  - `POST /security/injection/enforce`: screen prompt inputs.
  - `POST /security/injection/scan_tool`: screen MCP tool metadata definitions.
  - `POST /security/injection/normalize`: inspect prompt normalization.
  - Off-switches returning HTTP 503 if disabled.
- Implement TypeScript contract `PromptInjectionClient` in `locus-extension/src/security/prompt-injection.ts`.
- Write unit tests in `tests/unit/test_injection_filter.py` and integration tests in `tests/integration/test_injection_filter_service.py`.
- Pi table:
  - Need: Pre-execution prompt injection defense, Unicode confusable normalization, and tool metadata screening before tool dispatch.
  - Pi mechanism: Pi has extension hooks in `packages/coding-agent/src/index.ts` (`beforeToolCall`) but lacks prompt injection screening, confusable normalization, or scoring DFA rules.
  - What Locus adds: Full synchronous injection filter pipeline in `sidecar/security/injection_filter.py`, `sidecar/providers/injection_filter.py`, and `locus-extension/src/security/prompt-injection.ts` with 6-stage normalization, scored rules, 0.55/0.70 thresholds, tool scanning, and REST endpoints with 503 off-switch.
  - Why Pi's is not enough: Pi passes user prompts and tool outputs directly to the LLM without Unicode homoglyph or zero-width sanitization, exposing it to prompt injection and credential exfiltration attacks.

## Security (anything found, even if outside this story)
- Zero-width character and Unicode homoglyph normalization eliminates evasion attacks against prompt filters.
- Strict PII-safe audit logging records only SHA-256 hashes of input prompts, ensuring raw user inputs and potential credential payloads are never leaked into log streams.
- Exfiltration intent rule deliberately excludes high-false-positive verbs (show, give, tell, fetch) per issue #1940.
- Modular off-switches return HTTP 503 with explicit disable metadata.
