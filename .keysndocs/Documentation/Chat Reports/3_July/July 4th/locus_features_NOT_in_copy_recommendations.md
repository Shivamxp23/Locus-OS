## Key Observations

1. **Infrastructure features are 100% absent** — the copy recommendations matrix treats Locus's existing infrastructure (VM, Docker, Cloudflare, FastAPI, self-maintenance, DB mirror, admin dashboard, staging) as given, not as features to compare. All 8 infrastructure features are missing.

2. **Life-OS mechanics are partially covered** — Core System features like Faction Weekly Stats (#6), Behavioral Event Stream (#7), Dead Node Detection (#10), Momentum Score (#15), Parallel Task Optimizer (#16), Three-birds-one-stone (#17), Dijkstra's Scheduling (#128), Habit Graph (#131), and Task Quality Score (#132) are all missing. Some map to high-level concept rows in Section 25, but the specific implementation features are not named.

3. **Hermes-sourced features (#87-123) have uneven coverage** — features that mirror what the matrix already covers for Locus (agent loop, context compression, providers, tools) are well-covered. But Hermes-specific patterns (pluggable context engines, multi-profiles, autonomous curator, skin engine, Ink TUI, achievements, Langfuse, special capabilities, work queue, standalone plugins) are not.

4. **Newer integrations are absent** — NotebookLM (#76), Notion (#133), Google Photos (#134), Instagram (#136), and scheduled voice calls (#130) were not in the original `full_feature_matrix.md` that the copy recommendations was built from.

5. **The matrix was built from a different source** — the copy recommendations was generated from `full_feature_matrix.md`, which had 312 rows across 29 sections. The annotated file has 142 items organized differently. The two documents have different taxonomies, so complete 1:1 mapping is not always possible.
